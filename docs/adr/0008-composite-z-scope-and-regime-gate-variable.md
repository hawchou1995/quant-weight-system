# ADR-0008: 复合因子截面归一必须在可交易域内；regime 闸门变量必须匹配池的 beta 变量

日期：2026-09-13 ｜ 状态：已接受 ｜ 来源：因子挖掘实验室 R1-R5（报告-因子挖掘实验室R1-R5_20260913.md）

## 背景

主板多因子线 R1-R5 五轮预注册挖掘（155 网格臂 + 4×500 安慰剂）：champion（icir 6 因子 + Top20 月频 + 中证1000ETF MA20 半仓闸门）相位中位 Sharpe 0.754 / 年化 +9.6%，安慰剂 p=0.000 但**未过 Sharpe≥1 硬闸**，且收益集中 2024-25（年度集中度否决）——观察候选不投产。过程中固化两条与具体参数无关的结构性规则：

## 决定

1. **复合因子截面归一的截面 = 可交易 eligibility 截面**。对全市场截面做 z-score 再在 eligibility 子集内选股，会使因子五分位差主要来自不可交易的尾部（低流动性地板之下），组合级兑现塌掉。R1（全截面 z）→ R2（eligibility 内 z）相位中位 Sharpe 0.39 → 0.58，同参数直接对比。后续任何 composite/信号归一默认在"实际可下单的候选域"内做。
2. **regime 闸门的变量必须与池的 beta 变量同族**。小盘/流动性池的仓位闸门用 HS300 MA（大盘趋势）是错误变量：小盘溢价恰在大盘弱期兑现（R2：HS300 MA120/60 闸门把年化 9%+ 砍到 1-3%）；换中证1000ETF MA20 后闸门才与池回撤对齐（R3：MDD −22%→−15%）。**半仓暴露优于全开全关**（R4：闸门期目标仓位减半，icir+half off0 S 0.78 / MDD −17.2%，优于同权全关与不闸门）。

## 增补（0913 下午 R6 轮）

3. **eligibility 流动性地板是结构参数，必须与资金规模联动推导**：5000万地板是筛选默认值，17 万本金参与率 <0.1% 时地板下探（5000万→300万）使 phmed Sharpe 0.754→1.107 单调改善（剂量曲线见报告 §十）。地板过高会把因子五分位差锁死在不可交易域之外（与规则 1 同构的池定义错误）。100 万口径同配置 S 1.10 无劣化；更大资金需重推地板。

## 后果

- 后续因子组合研究直接引用本 ADR 的两条规则，不再重跑同型对照（HS300 闸门×小盘池 = 已证伪构型）。
- champion 配置（见报告 §二）列观察候选，模拟跟踪与否由用户拍板；不进任何实盘资金分配。
- 多因子股票线的解锁条件（分红/SUE/资金流数据）见报告 §八。

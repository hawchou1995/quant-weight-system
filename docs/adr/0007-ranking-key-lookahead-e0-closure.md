# ADR-0007: 排名键前视陷阱——E0 流动性轮动家族关闭

日期：2026-09-13 ｜ 状态：已接受 ｜ 取代：ADR-0006 中「E0 原样为唯一投产候选」及其全部增补的投产判定

## 事件

E0（主板高流动性 Top N 月度轮动）全部轮次（识别→优化→升级→小资金定稿，报告口径 +121%~+378%）的
选股排序键 LIQ_RANK = **按全历史最大 amt20 静态排序**——该键在回测起点就包含未来信息（哪些公司
在 2025-26 年会成为成交额巨头）。投产定稿前（用户 17 万实盘配置环节）补做无前视口径时发现：

| 口径（17 万/整手/最低佣 5 元） | off0 | 十相位中位 |
|---|---:|---:|
| 静态排名（前视，历史全部数字） | +297.4%（LLV30N10） | — |
| **动态排名（当日 amt20，实盘可执行）** | **−20.1%** | **−35.0%** |
| 动态排名（LLV20N10） | −22.5% | −30.3% |
| 动态排名基线（MA20N5） | +34.6% | −32.3% |
| 持续活跃度排名（amt20 的 120 日均值，无前视质量代理） | −16.0% | −34.6% |

## 判决

1. **E0 家族全部关闭**：静态排名的全部正期望来自排名键前视。无前视的任何排名键（当日热度、
   平滑活跃度）均为负期望——「主板月度轮动买最活跃的票」本质是追热点接盘，与 r2 根因
   （横截面反转市场、追强=负 IC）同构。ADR-0006 的相位硬闸结论**仍然有效**（同池横向对比方法学），
   但其上的一切绝对收益与投产判定作废。
2. **ML-N 阶梯止损的相对优势降级**：前视池内 10/10 配对全胜；无前视池内 5/10 平手——退出函数的
   改善依赖池的质量，不构成独立正期望来源。书籍语料结论（R 乘数、跟踪止损原理）仍为知识资产。
3. **股票中长线第七重证伪收敛**：日线 OHLCV 域 + 流动性轮动域全部关闭。项目正期望唯一仍为
   **FB3-H20 基金动量轮动**（基金 NAV 动量，无个股前视问题，已投产）。

## 根因与方法论固化（新增硬闸）

- **排名键前视**：`sorted(key=lambda cc: -np.nanmax(stock[cc]["amt20"]))` 式的「历史最大值」排序键
  是回测经典陷阱——max 窗口含未来。**任何选股/排序键必须仅用 T 日及以前可得信息**；
  涉及排序键的历史回测结论必须声明键的信息集。
- **投产前最后一道闸**：实盘定稿前必须以「无前视口径」重跑全部分析（本轮在用户配置环节才做，
  晚了——今后并入标准流程：新策略首次回测即用动态/无前视口径，静态口径仅用于横向对比）。
- 幸存者偏差、相位、多重检验之外，**信息集审计**为第四道标准审计。

## 后果

- 用户 17 万实盘配置搁置：不按任何 E0 变体建仓。
- 优化资源转向：FB3-H20 运行维护、待办①短线②打板③基本面数据源立项（该域的信号若全部基于
  T 日可得财务信息，天然无此类前视）。

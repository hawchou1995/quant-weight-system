# ADR-0006: 主板高流动性轮动的正期望来源在池，相位是第一过拟合维度

日期：2026-09-12 ｜ 状态：已接受

## 背景

E0（高流动性 Top10 月度轮动+MA20/−8%/60 日退出，2021 起 +121.05%/夏普 0.791）投产前优化轮：
黄金分割融合、权重向量穷举、调仓节奏共 45 臂 + 随机权重安慰剂 2×500 + 相位扫描 26 臂。

## 决策

1. **黄金分割与权重向量两方向正式关闭**：入场侧低吸（−11.86%）、fib 排序/支撑止损、9 种权重形状、
   3 种因子加权全部无正增量；随机 Dirichlet 权重（池固定）中位即达夏普 0.696，动量加权名义优势
   p=0.196 不显著。未来同类信号（任何「池内怎么配、怎么低吸、怎么画线止损」）直接引用本 ADR 不重跑。
2. **任何 rebal/调仓日历变更必须过全相位扫描**（offset ∈ {0…rebal−1} 至少 6-8 档）：
   R40 off0 夏普 1.055/收益 160.31%，相位中位仅 66.7%（最低相位 +9.4%）——off0 尖峰≠策略优势。
   R20 基线 off0=121.05% ≈ 相位中位 113.1% 才是稳健形态。
3. E0 维持原样为唯一投产候选；M7（动量加权 N7）名义过安慰剂但家族校正后无效，仅列观察候选。

## 理由

- 池（amt20 Top10）的构成与暴露承载全部正期望；截面上的仓位分配、出场细化、节奏变化都在
  稀释或噪声化该暴露（与 ADR-0004「深跌反转不可组合化」同构：条件选出的是池内走弱票）。
- 分年度暴露（2021 −12.6/2022 −3.9/2025 +57.0）说明其本质是 AI/科技活跃大票的结构行情载体，
  权重微调无法改变该属性。

## 后果

- 省算力：权重/黄金分割/节奏三域不再为该载体立项；优化资源转向数据面（基本面立项章程待批）。
- 回测纪律新增一条硬闸：调仓日历类参数必须附相位扫描表，否则审计不通过。

## 增补（2026-09-12 晚，参数与权重全穷举后）

用户要求穷举 MA 周期（MA22 传闻）与其余参数、权重单纯形（~3000 臂/向量）后，本 ADR 全部结论加码：

1. **退出参数全部退化**：硬止损 ≥10% 从不生效（10/12/15/无 四档分毫不差=115.41%）、满 60 日从不约束、
   池大小（5/20/50）与流动性门槛（200 万~2000 万）全部=基线。E0 的真实自由度只有
   「全市场流动性 Top5 等权、20 日轮动、MA20 退出」。
2. **退出均线加长的 off0 曲面（MA40=338%/夏普 1.202）是相位运气**：MA40 口径相位中位 51.9%（坏相位
   5.7 年零收益）、2021-24 分年度合计 +0.6%；基线 MA20 相位中位 113.1% 仍最优。**不存在可投产的 MA 换挡。**
3. **权重单纯形全枚举（C(14,4)=1001×2 口径）+ Dirichlet 相位对照钉死权重维度**：极值向量
   [0,0.1,0,0.9,0] off0 1502.6%，8 相位中位 142.6% ≈ Dirichlet 120 随机向量相位中位分布的中位 143.4%
   （p=0.51）——穷举出的「最优权重」是对同一批骰子的复读。
4. **off0 语义澄清**：实盘「每月第一个交易日调仓」是固定规则，基线 off0 121.05% 对实盘者是真预期；
   但变体之间比较必须用相位中位（实盘启动日任意）。

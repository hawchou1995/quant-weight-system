## 三、权重设计与动态系数方案（吸收后）

### 方案 A：FG 动态门槛（推荐主方案）

- **作用层**：替代现有 `MARKET_ADJUST` 三档离散门禁，改为 FG 连续值动态调节
- **FG 计算**（推文方法论复刻，沪深300 日K 5 维等权）：

```
D1 动量：20 日收益率滚动分位（涨多=贪婪）
D2 趋势：收盘价/MA20 偏离滚动分位（强势=贪婪）
D3 波动率：20 日年化波动率分位（低波=平静=贪婪，取 100-分位）
D4 回撤：距 250 日高点回撤分位（接近高点=贪婪）
D5 量能：量比（当日量/20日均量）分位（放量=贪婪）
FG = 五维等权平均 ∈ [0,100]，滚动窗口 W=250
```

- **动态系数公式**：

```
dev = (50 - FG) / 50                      # 恐惧(FG<50)→dev>0
BUY_WEAK_eff  = BUY_WEAK  ± k_buy × dev  # 恐惧机会模式取「−」：门槛下移、更易加仓
SELL_STRONG_eff = SELL_STRONG ± k_sell × dev  # 同方向
钳位：BUY_WEAK ∈ [50,78]，SELL_STRONG ∈ [22,42]
```

- **方向选择**（回测实证）：**恐惧机会（逆向抄底）**——恐惧区加仓门槛下移、清仓阈值上移，与推文「积极信号在积累」的逆向逻辑一致

### 方案 B：FG 第 7 维权重

- 权重从六类等比例挤出 5%：`scale = 0.95`，`total = total × 0.95 + (100-FG) × 0.05`
- 恐惧（FG 低）→ (100-FG) 高 → 总分抬升 → 加仓倾向增强（同向逆向逻辑）

1. **FG 恐惧机会（逆向抄底）全维度占优**：收益 +1.19pct、回撤持平（13.83% vs 13.84%）、夏普 1.676 最高、胜率 92.1% 最高、换手 0.772% 最低 → **风险调整后最优，已投产**（weight_score.py USE_FG_DYNAMIC=True / FG_MODE=opportunistic）

# 信号评估规则（v3.0 · 权重系统全权驱动）

本文件是监控任务的「规则书」。规则调整只需修改本文件，定时任务会自动按新规则执行。

## 信号体系（v3：六类加权打分唯一驱动）

> **v3 变更（2026-08-11）**：S1-S7 事件信号体系与 SPI 指标已**彻底废弃**（用户决策）。
> 信号判定完全由「量化权重系统 v1.4」六类加权打分驱动；超买超卖类使用 **RSI(14)**（知识库 2026-08-10 澄清：「SPI」为 RSI 的错误叫法）。

| 类别 | 权重 | 打分构成（满分） | 说明 |
|------|------|----------------|------|
| 趋势类 trend | 30% | MA20位置(40) + ADX(30) + 20日动量(30) | USE_MID_MA=False（二期验证双输） |
| 动能类 momentum | 25% | MACD状态(50) + 当日涨跌ATR自适应(30) + 柱动能(20) | S1/S2 阈值已并入（ATR 自适应） |
| 量能类 volume | 15% | 量比(50) + 量价配合(50) | **A3 高低位区分**：高位放量跌 8 分/低位 20 分 |
| 超买超卖类 osc | 15% | RSI(14)(60) + KDJ三重过滤后(40) | RSI>80 超买 / <20 超卖；KDJ 位置+趋势+动能三闸门 |
| 风控类 risk | 10% | ATR适中(50) + 距60日高点回撤(50) | 唯一惩罚性类别（权重敏感性实验后维持 10%） |
| 研报类 news | 5% | L1=70 / L2=50 / L3=30 / L4=20 | 人工分级，静态赋值 |

总分 = Σ(类分×权重) ∈ [0,100]。

## 操作档位（市场状态调节）

| 市场状态 | 判定 | 满仓加仓 | 轻仓加仓 | 观望 | 减至半仓 | 清仓 |
|---------|------|---------|---------|------|---------|------|
| normal 正常态 | 沪深300 ≥ MA20 | ≥75 | 60-74 | 45-59 | 30-44 | <30 |
| weak 防御态 | 沪深300 < MA20 | ≥75 | **65**-74 | 45-64 | 35-44 | **<35** |

- 稳健加减仓 = 目标制 + 单次上限 50%（v1.4 target_cap，用户拍板）
- 置信度：覆盖率≥80% 且方向一致≥75% → 高；覆盖率<60% → 低；其余中
- 档位变化跟踪：对比上次操作档位（信号状态.json 的 actions 字段）

## 情报层（研报）与事件标注

- **研报情报**：L1-L4 仅作研报类打分输入（权重 5%），方向一致时加分（L1=70）、谨慎时减分（L3=30）
- **事件标注**（标注式，不改打分）：`events.json` 维护，看板/报告以 ⚠ 展示（如 FCC 光模块禁令风险）

## 标的池格式（watchlist.json）

**通达信 setcode 推导（自动）**：6/51/56/58/68 开头（沪市）→ `"1"`；0/3/15 开头（深市）→ `"0"`；港股 → `"31"`；**场外基金 → `"33"`（必须传 `target="1"`）**。

JSON 数组，每项一个标的：

```json
[
  {"code": "300502", "name": "新易盛", "type": "股票", "market": "SZ", "setcode": "0", "note": "光模块"}
]
```

**增删方法**：直接告诉 AI「加 XX」「删 XX」，或手动编辑本 JSON 文件。

## 输入指标（每日由行情计算）

| 指标 | 含义 |
|------|------|
| pct_chg / vol_ratio / ma20_dev / close>MA20 | 当日涨跌 / 量比 / 偏离 / 趋势位置 |
| MACD(12,26,9) / KDJ(9,3,3) / RSI(14) / ADX(14) / ATR(14) | 六类打分输入（权重系统） |
| dd60 | 距 60 日高点回撤（短窗口退化） |
| 市场状态 | 沪深300 收盘 vs MA20（indices.json） |

**数据要求**：股票/ETF 的 raw_kline 需含 h/l 字段（KDJ/ADX/ATR 计算必需）；场外基金无日内高低价 → 量能类退化中性 50，ATR/ADX 用收盘价退化。

## 操作建议映射

| 档位 | 操作参考建议 |
|------|-------------|
| 满仓加仓/轻仓加仓 | 分批加仓（单次最多调整 50% 仓位） |
| 观望 | 维持现状，等待信号明确 |
| 减至半仓/清仓 | 减仓/清仓（单次最多调整 50% 仓位） |

## 信号变化跟踪

每次运行后，将当日档位写入 `信号状态.json`（actions 字段）；下次运行时与上次对比，报告中标注「档位变化：观望 → 轻仓加仓」等提示。

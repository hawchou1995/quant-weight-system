## 0. 一句话定位

**这是一个「单笔算术期望为正、但组合复利深度为负」的实验系统。** 它的价值不是直接盈利，而是用真实盘面数据验证「首板次日低开 2-5% + 日内冲高 +8% 止盈」这个边缘是否真实存在。**验证通过前，只允许模拟盘跟踪，禁止实盘。**

## 1. 精确规则（与回测口径逐位一致）

### 1.1 信号定义（首板次日低开）

| 条件 | 口径 |
|---|---|
| 首板日 T-1 | 当日涨停（主板 ≥9.5% / 创业板 ≥19.5%）且**非一字板**（open==high==low==close）且**前一日非涨停**（连板排除） |
| 入场日 T | 首板次日，开盘低开 **2% ~ 5%**（gap = open/prev_close - 1 ∈ [-5%, -2%]） |
| 过滤 | 首板日 rel_pos(60日) ≤ 0.5（相对位置不追高）且 成交额(vol×close) ≥ 5000万 |
| 排除 | 入场日一字板、成交量=0、开盘=0 |

### 1.2 出场规则（tp_t2：日内冲高止盈 + 收盘兜底）

| 时点 | 规则 |
|---|---|
| T+1 | 日内 high ≥ 入场价×1.08 → **止盈价卖出**（tp）；否则**收盘卖出**（ts） |
| T+1 涨停 | 不卖，顺延至 T+2 |
| T+2 | 同 T+1 逻辑（冲高止盈 / 收盘卖） |
| T+2 涨停 | **收盘强平**（force，与回测一致） |

### 1.3 成本与池

- 成本：买 0.525%（佣金+滑点）/ 卖 0.625%（佣金+印花税+滑点）——模拟盘按实际成交价计算，不额外加滑点
- 池：主板+创业板（600/601/603/605/000/001/002/003/300/301），剔 ST/退/S 开头/北交所/科创板/ETF
- 数据：`D:/Documents/Quant data/data_full` 前复权日线，收盘后（15:30 数据刷新后）运行

### 1.4 A2_tp3 回避清单（v1.1 新增 · 负期望警示 · 不单独交易）

**定位**：配置穷举（78 主扫描 + 8 首轮 = 86）中「胜率≥50 的最优」是 A2_tp3（胜率 63.1%），但它是**负期望**模型（单笔均值 -1.39%）。grill-me 拷问后用户拍板：**不交易它，把它挂成回避清单**——负期望信号的反面是信息，用于持仓减仓观察。

| 条件 | 口径 |
|---|---|
| 信号 | 首板次日低开 **2% ~ 6%**（gap ∈ [-6%, -2%]） |
| 过滤 | 首板日 rel_pos(60日) ≤ 0.7 且 成交额(vol×close) ≥ 5000万 |
| 出场（回测口径，仅用于刻画） | tp_sl：+3% 止盈 / -5% 止损 / 3 日时间止损 |
| 回测统计 | 胜率 63.1% · 均值 **-1.39%** · 盈亏比 0.29 · n=1,730 |

**用法**：每日报告输出「⚠ A2_tp3 回避清单」——命中标的标注「负期望警示：次日大概率冲高回落，建议回避/减仓」。**不单独交易、不加入观察清单、不记录模拟盘**。

**与 A5 主模型的关系**：A5 入场信号（gap∈[-5%,-2%], rel_pos≤0.5）是 A2_tp3 信号的**子集**——每个 A5 入场都同时命中回避清单。含义：A5 信号本质是「低质量信号」，其正期望完全依赖 tp_t2 出场结构（8% 止盈截断右尾 + T+2 兜底），**若出场纪律松动（恋战/改止盈），A5 会退化为 A2_tp3 的负期望形态**。因此回避清单是 A5 持仓的纪律提醒：严格执行 T+2 兜底，不恋战。

## 2. 回测基准（2016-01-01 ~ 2026-08-26，全量 4444 只）

### 2.1 单笔统计（全部信号 n=1,116）

| 指标 | 值 | 说明 |
|---|---|---|
| 胜率 | **46.1%** | 低胜率形态（用户已接受） |
| 均值净收益 | **-0.17%** | @0.5% 滑点 |
| 均值毛收益（零成本） | **+0.99%** | 边缘真实存在 |
| 中位数 | -0.63% | 多数小亏 |
| 盈亏比 | 1.10 | 赢的平均 > 亏的平均 |
| tp 出场占比 | 21.5% | 约 1/5 触发 +8% 止盈 |
| 平均持有 | 1.06 天 | 极短持有 |

### 2.2 组合信号统计（n=625，每日≤5 + 板块去重 + 情绪门控）

> ⚠ 2026-08-28 修正：此口径**仅供展示**（若未来实盘加组合限制后的参考），**非验证门基准**——验证门基准见 §3（全部信号口径）。

| 指标 | 值 |
|---|---|
| 胜率 | 45.0% |
| 均值净收益 | **+0.11%** |
| 均值毛收益（零成本） | +1.27% |
| tp 出场占比 | 22.4% |

### 2.3 ⚠ 组合净值（等权叠加、全持有期逐日复利）——必须正视

| 指标 | 值 |
|---|---|
| 总收益 | **-72.2%**（1004 个持仓日） |
| 年化 | **-27.4%** |
| 最大回撤 | **-91.4%** |
| 夏普 | -0.11 |

**为什么单笔为正、组合为负？** 算术期望 +0.11%/笔 远小于日波动（σ≈5%/日），几何复利 ≈ 算术均值 − σ²/2 < 0。这是「低胜率正期望」形态的固有属性：**边缘太薄，方差太大，复利吃光边缘**。任何实盘都必须以极小仓位（单笔 ≤1-2%）运行，且接受长期净值曲线难看。

### 2.4 成本敏感性（滑点 0.2% 时）

| 滑点 | 单笔均值净收益 |
|---|---|
| 0.5%（回测基准） | -0.17% |
| 0.2% | **+0.43%** |
| 0.1% | +0.63% |

→ 边缘对执行成本极度敏感：**1.15% 往返成本 > 0.99% 零成本边缘**。实盘若滑点 >0.3%，边缘即被吃光。

## 3. 验证门（模拟盘判定标准）

**触发条件：累计 30 个已平仓信号 或 运行满 3 个月（先到为准）**

> ⚠ **基准口径（2026-08-28 修正）**：验证门基准 = **全部信号口径**（§2.1，46.1%/-0.17%/21.5%），
> **不是**组合信号口径（§2.2，45%/+0.11%/22.4%）——因为模拟盘扫描器**未执行**每日≤5/板块去重/情绪门控
> （组合限制），实际执行就是全部信号口径。**基准与执行必须同口径**，否则判定偏乐观
> （组合口径均值 +0.11% 为正、全部信号口径 -0.17% 为负，差一个正负号）。

| 闸 | 回测基准（全部信号） | 通过区间 |
|---|---|---|
| 胜率 | 46.1% | [35%, 55%] |
| 均值净收益 | -0.17% | > -0.5% |
| tp 出场占比 | 21.5% | [12%, 32%] |

- **三闸全过** → 边缘确认，可考虑小仓位实盘（单笔 ≤1%，总仓位 ≤5%）
- **均值净收益 < -1%** → 边缘证伪，**立即停止**。**⚠ v1.2（2026-09-15）适用条件修订（用户拍板）**：该停止线**仅在累计已平仓信号 n ≥ 30 时适用**（与项目"n<30 不可判定"纪律一致）；n<30 期间该线不生效、继续积累。**当前越线事实记录在案**：截至 2026-09-14，已平仓 11 笔、均值 −1.71%（4 胜 7 负）、tp 出场占比 0%，n=11 < 30 → 按修订线继续积累；n 达 30 首日若均值仍 < −1% 即停止。
- 其余 → 继续积累信号

## 4. 风险规则（若未来实盘）

1. **单笔仓位 ≤1-2%**（边缘太薄，方差太大，重仓必死）
2. **总仓位 ≤5%**（组合复利为负，只能当卫星策略）
3. **单日最多 5 只**（与回测一致），板块去重
4. **情绪门控**：当日涨停数 <20 或 连板高度 <2 或 炸板率 >50% → 单日最多 2 只
5. **T+2 收盘无条件清仓**（不恋战，涨停日除外按强平规则）
6. 滑点 >0.3% 的环境（流动性差/一字板多）不交易

## 6. 已知边界

1. **信号稀疏**：回测 10 年 1,116 信号 ≈ 105 信号/年，日均 <0.5 只——验证门 30 信号需约 3-4 个月
2. **数据依赖**：依赖 data_full 收盘刷新（15:30 收盘任务）；停牌股自动跳过
3. **一字板排除**：首板一字板（买不进）与入场日一字板（低开不成立）均排除
4. **行业映射**：读 `quant-weight-system/stock_industry.json` 的 `map` 字段（6 位代码键）
5. **模拟盘无滑点模型**：按实际开盘/收盘/止盈价成交，实盘需自行加滑点预算

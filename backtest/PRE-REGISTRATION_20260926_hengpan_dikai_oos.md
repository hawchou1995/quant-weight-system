## 1. 冻结策略规格（逐条、无歧义）

**信号日 T（收盘后判定）**

1. 股票资格：`有效价(close>0)` 且 `上市有效交易日 ≥ 250` 且 `close[T] ≥ 2.00 元` 且 `AMT20[T] ≥ 2,000 万元`
   - `AMT20` = 过去 20 个有效日 `amount` 的均值
2. 次日跳空条件（在 T+1 开盘时判定）：`gap = open[T+1] / close[T] − 1 ∈ [−3.00%, −1.00%]`
   - 即：**低开至少 1%，但不得低开超过 3%**
3. 复合打分（在**当日全部满足 1+2 的候选**上做横截面标准化）：
   ```
   F = z(−ln AMT20) + z(−ln VOLBR) + z(−RET20)
   VOLBR = volume[T] / VMA20_prev[T]      # VMA20_prev = 过去 20 有效日均量
   RET20 = close[T] / close[T−20] − 1
   z(x) = (x − mean) / std               # 当日候选池内
   ```
4. 选股：按 `F` 降序取**前 10 只**（每日最多 10 只，不足则全买）
5. 仓位：每只 `= min(前一日净值 / 20, 可用现金)`；最多同时持有 20 只；**同一标的持仓期内不重复买入**

**交易**

6. 买入：**T+1 开盘价**（集合竞价，单一价格撮合）
7. 卖出：**T+2 收盘价**（尾盘）
8. 出场价缺失（停牌）：顺延至下一个有效价；若 5 个交易日内无有效价，则取最近有效价；仍无则按 0 计（清零）
9. 成本：**双边 6.92 bp 往返** = 佣金 万0.86×2 (1.72bp) + 印花税 5bp（卖出）+ 过户费 0.1bp×2 (0.20bp)
10. 净值：逐日收盘盯市

### E-1｜`shadow_start` 的语义澄清（**非规则变更**）

| 日期 | 星期 | 是否交易日 |

| **2026-09-24** | 周四 | **是（节前最后一个交易日）** |
| 2026-09-25 | 周五 | **否（中秋节休市）** |
| 2026-09-26 / 09-27 | 周六 / 周日 | 否 |
| **2026-09-28** | 周一 | **是 ← `shadow_start` 的实际生效日** |

运行器以**交易日历索引**扫描（`首个 d ≥ shadow_start 的交易日`），因此功能上等价于 `shadow_start = 2026-09-28`，无需改动，也**不应改动**（改则 SHA 变化、OOS 作废）。

### E-3｜口径错误留档（我的错）

2026-09-26 的汇报中我称：「本地 `data_full` 止于 2026-09-24（今日 09-26），云端链 15:05 会自动更新」——**错误**：

## 勘误与澄清（续，2026-09-26 第二轮）

### E-4｜冻结脚本规格偏差更正（**预观察期更正 —— 不是事后改规则**）

**偏差**：`ooos_run.py` 中 `VOLBR`（放量比）被实现为 `volume[T] / mean(volume[T−19..T])` —— **窗口含当日 T**；而预注册 §1 的定义与**样本内全部研究**均为 `VOLBR = volume[T] / VMA20_prev[T]`，其中 `VMA20_prev = mean(volume[T−20..T−1])` —— **窗口不含当日**。

**检出方式**：`watch_next.py` 内置的「与样本内面板对拍」自检。初次运行即报 `VOLBR 绝对最大差 6.02e+02`（AMT20 与 RET20 均为 `0.00e+00`）。
> 触发链条：用户指出「其实跑一下 9/24 收盘数据，9/28 看信号切入也行」→ 我去做盘前候选表 → 加了自检 → 撞出此偏差。

**影响**：若按原脚本运行，OOS 将验证一个**与样本内不同的规则**，两边结果不可比。含当日的窗口会因当日放量进入分母而系统性压低放量比，改变选股结果。

**更正**：`oos_run.py` 的 VOLBR 改为滞后定义（`VMA20_prev`），与预注册及样本内完全一致。

**SHA 变更**：`53040b9c…a6fe`（v1.0，已废）→ **`32d35f71b7f338bd9908e590d049c03e8af861bfa2888da21595e4c15c971e18`（v1.1，现行）**。`oos_state.json` 与 `oos_report.json` 已同步为 v1.1 哈希，**脚本 / state / report 三方互证一致**。

**为何不违反 immutability**：更正发生在**任何 OOS 观测之前** —— 此刻 `n_settled = 0`、`last_data_date = 2026-09-24`（早于 `shadow_start`）、首个信号日（09-28）尚未发生。**规则、判据、参数、股票池一律未变**；本次更正只是把**写错的实现**对齐到**已冻结的定义**。若已产生观测再改，则必须重启 OOS —— 本次不需要。

**验证**：更正后 `watch_next.py` 自检三项特征与样本内面板对拍差均为 `0.00e+00`。

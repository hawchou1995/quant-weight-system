## 一、动机（已实测，非推测）

分层分解结果（比值 = 后段 2022-2026 / 训练 2016-2021）：

| 层 | 比值 |
|---|---|
| 超跌条件本身 | **1.01 ~ 1.02**（稳定） |
| 熊市门 | 1.41 |
| **市值 50-200 亿** | **1.73** |
| **换手 5%-10%** | **2.02** |
| 量比 ≥1.2 | 1.04（稳定） |
| 非 ST | 1.11（稳定） |
| gap 低吸 | 1.01（稳定） |

**机制**：绝对区间随市场结构漂移（落在 50-200 亿流通市值区间的股票变多、换手中枢抬升），
它不是经济条件，是一个随年份漂移的百分比。→ 换成**当日横截面分位带**可使其逐年可比。

## 三、臂设计（6，先验声明）

分位 = 该股当日数值在**当日全部有效股票**中的分位（非 COMMON 过滤后 → 非自指）。
量比与非 ST 保持绝对（其比值 1.04 / 1.11 已稳定，不必改）。

| 臂 | 市值 | 换手 |
|---|---|---|
| **B0** | 绝对 [50, 200] 亿（对照） | 绝对 [5%, 10%] |
| **B1** | 分位 [0.30, 0.70] | 分位 [0.50, 0.80] |
| **B2** | 分位 [0.30, 0.70] | 绝对 [5%, 10%] |
| **B3** | 绝对 [50, 200] 亿 | 分位 [0.50, 0.80] |
| **B4** | 分位 [0.20, 0.70]（更宽） | 分位 [0.40, 0.80]（更宽） |
| **B5** | 分位 [0.40, 0.60]（更窄） | 分位 [0.60, 0.85]（更高换手） |

B2 / B3 单变量归因；B1 双改；B4 / B5 宽度敏感性。

## 四、判据

**首要（唯一目的）**：完整信号的两段比 **≤ 1.5**。
（该判据上一轮 9 臂全不过，本轮就是要看分位化能否压下来。）

**次要（防止稳定性换掉 alpha）**：
- 训练窗 单笔净均 > +0.30%
- 训练窗 单笔净中位 > 0
- 训练窗 胜率 > 52%
- 训练窗 回撤 > −40%
- **训练窗夏普 ≥ 基线 B0**（硬约束：不得用稳定性换 alpha）
- 训练窗笔数 ≥ 100

## 五、预设退出

1. **无一臂两段比 ≤1.5** → 分位化不能治膨胀 ⇒ 判"结构性漂移不可由条件构造消除"，收手，C1 维持原样
2. 有臂过稳定性门但训练窗夏普 < 基线 → **不采纳**（稳定性不能换 alpha）
3. 有臂同时过稳定性门与 alpha 门 → **登记为候选**，须封存集一次性验收后才可投产

## 六、披露

- 分位带宽度与绝对区间**不等价**，各臂信号数不可直接比；报告须同时给笔数
- 稳定性比值使用全窗（跨两段），属结构性指标；若读者认为这构成对已用 OOS 的二次使用，
  可只看训练窗 alpha 判据——两者结论若冲突，以"不收手"为准（保守）

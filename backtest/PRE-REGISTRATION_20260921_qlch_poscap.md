# PRE-REGISTRATION · 持仓数上限（消「单票满仓」）（R-qlch-poscap-0921l）

> 触发：用户 2026-09-21「批准下一步预注册」
> 上游：`报告-qlch滤网分位化-B4双门并过-20260921.md` §八（补充证伪）
> 核心病灶：现口径每日把 **100% 资金**等权分给当日信号 → **248 天为「单只股票满仓」**，
>           该 248 天贡献 **43.3%** 的总日收益；而 65.7% 的笔挤在 52 个拥挤日、只贡献 5.3%。

---

## 一、问题陈述

现口径（C1 与 B4 同）在信号稀疏日把全部资金压进 1 只票。这不是组合，是单票满仓。
**该约定的收益贡献占 43.3%，使整体年化（+33.35%）不可按字面采信。**

## 二、改动（唯一变量：单票权重上限）

**单票权重 = `min(1/n, 1/K)`**，n = 当日信号条数，K = 持仓数上限：

| n 与 K 关系 | 行为 |
|---|---|
| `n ≤ K` | 每只权重 `1/K`，**剩余 `(1 − n/K)` 资金持现金**（不放杠杆、不摊到单票） |
| `n > K` | 从当日信号中取 K 只（随机，固定种子集），每只 `1/K`，满仓 |

**取 K 只的规则**：随机抽取（**不做任何排序**——按深度排序会引入新的选择规则，
与本轮"只改权重上限"的单一变量原则冲突）。5 个固定种子（20260921…20260925），报告均值。

其余全部冻结：超跌 `ret20(T-1)≤−7.31%` / gap `[−5%,−2%]` / 熊市门 `HS300<MA20` /
H=1 / 量比 ≥1.2 / 非ST / **B4 分位滤网**（市值 [0.20,0.70]、换手 [0.40,0.80]）。

## 三、臂设计（n_trials = 5）

| 臂 | K | 说明 |
|---|---|---|
| **K0** | ∞ | 对照 = B4 现口径（无上限） |
| K1 | 3 | 最严 |
| K2 | 5 | |
| K3 | 10 | |
| K4 | 20 | 近无上限 |

成本 20bp 主档 + 50bp 压力档；未用资金默认持国债ETF（与既有口径一致），并附「未用资金 0 收益」对照。

## 四、判据

**首要（结构目标）**：单票最大权重 ≤ 25%（K≥4）。K=3 为 33.3%，K=5 为 20%，K=10 为 10%。

**次要（不得摧毁 alpha）**：
- 全期年化 ≥ B4 基线 × 0.8
- 夏普 ≥ B4 基线 × 0.8
- 回撤 ≤ B4 基线（即不劣化超过 0）
- 训练窗（2016-2021）单笔净均 > 0

**一致性硬门（本轮新增，针对 §八.3）**：
- **双口径符号一致的年数 ≥ 8/9**
- **2026 单笔净均 ≥ 0**（B4 现口径为 −0.620%）

## 五、预设退出

1. **无任何 K 能同时满足「年化≥0.8×基线」与「双口径一致 ≥8/9」** → 判「集中度换 alpha」不可解，
   B4 维持现口径登记为候选，持仓上限作废
2. 有 K 过门 → 登记为 B4 的**执行层修正**（不改信号，只改资金分配），随 B4 一起进封存集
3. **禁止**：不得为挽救年化而调回无上限；不得对 K 做细网格搜索（5 档已足够，多一档都是烧预算）

## 六、披露

- 随机取 K 只 → 存在抽样噪声，故用 5 种子取均值；单种子结果不单独报告
- 单票权重上限改变了资金利用率，年化下降是**预期的**，不是失败
- 本轮 n_trials = 5，累计 55 + 5 = **60**
- 仍只用 2016-2021 选型；已用 OOS 段仅报告；封存集（2026-09-22 起）不碰
- 若 K 门通过，**B4 与 K 的组合须在封存集上一次性验收**，不得分段验证

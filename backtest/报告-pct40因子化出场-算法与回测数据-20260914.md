## 一、算法定义（规则本身）

**pct40 = 持仓的复合 score 在截面上的分位跌出前 40% 即退出。**

执行语义（与项目 ADR-0006 口径一致）：

| 环节 | 规则 |
|---|---|
| 判定时点 | **T 日收盘**（用 T 日收盘数据算 score 分位） |
| 执行时点 | **T+1 日开盘卖出**（T+1 开盘价 ×(1−滑点)，含佣金 2.5bp 最低 5 元 + 印花税 5bp） |
| 卖出后 | **仓位留现金至下一调仓日**（不做即时补位——隔离出场效应，不引入额外换手） |
| 与定期轮动的关系 | 定期轮动（轨A 每 30 日/轨B 月频）**照常运行**；pct40 是**叠加的提前退出**（条件轮动） |

**两个载体的分位计算（方向相反）**：

| 载体 | score 定义 | 分位方向 | 触发 |
|---|---|---|---|
| 轨A 冷门低波 | `rank(ln amt20) + rank(atr20) + rank(turn20)` 升序（低=好） | 升序分位 | **> 0.40** 触发（跌出前 40%） |
| 轨B SUPER | 13 因子 ICIR 复合 z 分（高=好，`oss_super_prod_0913.COMP_SUPER`） | 降序分位 | **> 0.40** 触发 |

分位在**各自的可交易域**内计算（轨A：全主板 elig≈2938/日；轨B：300 万成交额地板 + ST/退市过滤后的域，见 ADR-0008"截面归一必须在可交易域内"）。

**实现（轨A，`exit_lab_trackA_0915.py` 核心逻辑）**：
```python
SPCT  = 每日 score 在域内的升序分位矩阵           # 低分位=好
IN2N  = 每日 score Top-40 布尔矩阵                # 对照臂用
...
# 每日收盘后（调仓逻辑之前）：
if exit_mode == "pct40" and SPCT[di, j] > 0.40:   # 持仓票跌出前 40%
    挂 pend_sell（次日开盘卖出），记录 n_exit
```

## 四、机制解释（为什么它有效，而止盈止损无效）

1. **它是"条件轮动"不是"止盈止损"**：固定阈值止盈止损（−15% 硬止损、MA20 破位、保本止损、黄金分割位止盈）在本项目**三次复核全负**——因为正期望全在右尾，阈值规则的本质是砍右尾；
2. **pct40 不碰价格阈值，只看"排名退化"**：跌出前 40% 才换，是"换掉真正变差的标的"，不预设涨跌幅；
3. **低频触发**：轨A 78 次/轨B 248 次（对比 ma20 的 890/914 次），保留右尾的同时剔除退化持仓；
4. **反例对照**：top2n（名单式 Top40）在轨A 还能过门但年化反降（593 次换手），在轨B 直接灾难（−2.150，因为超级分名单日频不稳）——**分位阈值稳健，名单式脆弱**是这轮最实用的工程结论。

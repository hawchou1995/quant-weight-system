# PRE-REGISTRATION · qlch 出场参数 X4 前向哨兵（R-qlch-sentinel-0923）

> 上游：`生产变更-qlch出场参数-20260923.md`（X0→X4 已生效，依据=事件级配对+机制一致性）· `报告-qlch-证据效力与可判定性-20260923.md`（功率）
> 触发：X4 已上生产，但**组合级未获确证**（配对 Δ日均/Δ夏普均不可判定，达功率门需 ≈122 年样本）→ 必须建一个**只读、只可否决**的前向哨兵，防止"改错了却没人知道"。

---

## 〇、定位（先写死，防止被误用）

| 项 | 值 |
|---|---|
| **职责** | **只可否决**（触发人工复核）；**无**自动改参/回滚权；**不**构成通过性证据 |
| 检出能力 | **只能发现粗差**：按功率分析，前向组合级分辨 Δ夏普≈1.0 需 ≈9 个月；≤0.3 的差异**永远测不出** |
| 数据 | **只读**现有账本（`backtest/qlch_paper_state_b4_k3.json` 生产轨）；不新增采集、不改链、不写账本 |
| 运行 | 由 PI 在每交易日回读时运行（**暂不并入日更链**，避免当日二次改链） |
| 判定节奏 | **≥60 交易日**（约 2026-12 中旬）首次正式判定；此前每日只**记录**指标、不判定 |

## 一、哨兵指标（每交易日记录，全部来自生产账本）

`n_trades` · `mean_net_pct`（单笔净收益均值）· `wr_pct` · `mean_hold` · `cum_ret_pct` · `mdd_pct` · `stop_share_pct`（止损类占比）· `expiry_share_pct`（到期占比）

## 二、否决规则（冻结；任一触发 → 人工复核）

| # | 触发条件 | 依据 |
|---|---|---|
| **V1** | 已完成交易 **≥20 笔** 且 `mean_net_pct ≤ 0` | 回测期望单笔 +9.29%（全池）；均值转负属粗差 |
| **V2** | `mdd_pct` ≤ **−61.5%**（= 回测 X4 全池最大回撤 −40.99% × 1.5） | 回撤超回测 1.5 倍 |
| **V3** | 累计 **≥60 交易日** 且 年化 ≤ **−5%**（回测验证窗 +10.49% 为参照，取 −5% 为粗差线） | 前向唯一可辨的是粗差 |
| **V4**（诊断，不设门） | `stop_share_pct ≥ 2×` 回测同窗占比 | 止损被打爆属结构性失效信号 |

**触发处置**：记录到 `backtest/qlch_sentinel_state.json` + 在回读里报告 + **不自动改任何参数**，由用户决定（回滚见生产变更记录 §二）。

## 三、明确不做 / 限制

1. 不做组合级配对（需并行 X0 臂 + 改链；本哨兵用的是"生产轨 vs 回测期望"这一弱口径，**不能**回答"X4 是否优于 X0"）。
2. 不做显著性检验（前向样本量不足）。
3. 不覆盖"事件级"层（该层已有预注册结论）。
4. 若样本长期不足（如成交稀疏），维持"记录中"状态，**不判负**。

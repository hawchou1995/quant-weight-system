## 一、冻结定义

- 位置度量（唯一、全臂统一）：`p = rel_pos60 = (C - min(L,60)) / (max(H,60) - min(L,60))`，取**信号日 T**（与各臂信号同日，无前视）
- **四段** = 位置四分位桶，按**当日全市场截面分位**切：
  - S1 低位（p < q25）
  - S2 中低位（q25 <= p < q50）
  - S3 中高位（q50 <= p < q75）
  - S4 高位（p >= q75）
- **命名口径申报**：原裁决单四名为「前置位 / 兑现位 / 洗盘位 / 高位」，属**结构角色命名**（须相对首板事件定位），
  无法对全臂统一定义 → 本轮**不采用**该命名，改用**截面四分位**这一可对全臂统一定义的操作化。
  映射仅供参考：S1≈洗盘位/前置位语境、S4≈高位/兑现位语境。**该操作化是我的选择，非原口径主张。**
- 臂样本：已封存信号 npz（A1/A2/B1/C1/D1/E1/F1）+ A5 生产事件（`oss_0913/daban_events_0915.csv` 双池并集）
- 事件口径：与 R-tdx6-0918 逐位一致——信号 T → 入场 T+1 开盘 → 出场 T+11 收盘，成本 20bp，超额 vs 全面板等权同期

## 二、A/B 设计

- **A（不闸）**：该臂全部事件，按四段分别报 n / 均值 / 中位 / 胜率 / 超额均值
- **B（加闸）**：仅保留 S1 低位段（单一先验形态，**不做"取均值最高段"的择优**——择优即 config-snooping）

## 三、冻结门槛（跨臂一致性，非单臂择优）

1. **单调性**：至少 5/8 臂的 excess 均值随位置分位**单调递减**（S1 > S2 > S3 > S4）
2. **段差显著**：S1 与 S4 的 excess 差 >= 0.5pp 且 Welch t >= 3.0，对至少 5/8 臂成立
3. **样本充足**：每臂每段 n >= 100

**结论口径**
- 三条全过 → 位置闸登记为**可复用工程件**（可对任意臂加闸）
- 部分过 → 登记为**条件性工程件**（仅在单调成立的臂上可用），并列出适用臂
- 全不过 → 「位置决定量价含义」降级为**单点发现**，不作工程件

## 四、n_trials 申报

- 8 臂 × 4 段 = 32 格（描述性切分，不构成择优臂）→ 计 4（四段）
- A/B 两形态 × 8 臂 → 计 2
- **合计申报 n_trials = 6**

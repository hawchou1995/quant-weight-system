### 证据 1-2｜`MINPX` 是**失效参数**（我自己查出来的实现问题）

`MINPX=2.0` 与 `MINPX=3.0` 的读数**逐位相同**。原因：预注册勘误 E-6 加的过滤件里

## 第三节 · 未来函数（2 条独立证据）

### 证据 3-1｜逐条件数据可用时点审计（代码级，决定性）

审计对象 = 冻结脚本 `oos_run.py` 的每一次取值。**判定时点 = T+1 集合竞价（09:25 前挂单）。**

| 量 | 计算式（脚本原文语义） | 用到最晚信息 | 判定 |
|---|---|---|---|
| `VALID` | `(C>0)&isfinite(C)&(O>0)` | T 日收盘 | ✓ |
| `NV` 上市有效日数 | `cumsum(VALID)` | T 日 | ✓ |
| `AMT20` | 过去 20 个**有效日** amount 均值（`min_periods=10`） | T 日（含 T） | ✓ |
| `VOLBR` 量比 | `V[t] / VMA20_prev[t]`，其中 **`VMA20_prev[1:] = VMA20[:-1]`** | T 日量 ÷ **≤T−1** 均量 | ✓ **显式滞后** |
| `RET20` | `Cv[t]/Cv[t−20] − 1` | T 日 | ✓ |
| `GAP` 跳空 | **`GAP[:-1] = O[1:]/C[:-1] − 1`** ⇒ **`GAP[t] = O[t+1]/C[t] − 1`** | **T+1 开盘价** | ✓（判定发生在 T+1 开盘时刻，见下"执行风险"） |
| `STP` ST 期内代理 | 过去 250 日**最大绝对日收益** ≤5.6% | T 日 | ✓ |
| `STNOW` 当前名 | `data_full_names.json` 含 `ST`/`退` | T 日静态名表 | ✓ |
| `BPSA` 每股净资产 | 报告期 **+4 个月** 后置（`usable_from` + `searchsorted`） | 报告期+4 月 ≤ T | ✓ **显式后置** |
| 复合分 `z` | 当日**候选池内** `mean/std` | T 日 + T+1 开盘 gap（决定池成员） | ✓ 同 `GAP` |
| 入场价 | `O[t+1]` | T+1 开盘 | ✓ |
| 出场价 | `C[t+2]` / 止盈 `O[t+2]` 或 `entry×1.02` | t+2 | ✓ |

**执行风险（不是未来函数，但必须并列披露）**：`GAP[t] = O[t+1]/C[t]−1` 要用**次日开盘价**做筛选，
而集合竞价**09:25 一次性撮合** ⇒ 想以开盘价成交必须 **09:25 前下单**，而那时只能看到**虚拟开盘价**。
本项目对 09:25 后买入单独做过回测：加价 ≤0.2% 可行（+118.48%），+0.3% 起快速衰减（+87.00%），
+1.0% 转负（−36.74%）。**这条是执行纪律，不是口径缺陷。**

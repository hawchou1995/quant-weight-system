## 四、网格空间（冻结，两类分开）

### 网格 I · 单因子阈值画像（**描述性**，不用于择优）
- 9 因子 × 阈值分位 `{10%, 20%, 30%, 40%, 50%}` × 持有期 `H ∈ {1, 5, 20}`
- = **135 格**；目的=**每个因子的独立效应画像**（含唯一标的数），非选优

### 网格 II · 组合与权重向量（**择优空间**）
- 阈值口径**固定为各因子取分位 30%**（**先验设定，不扫描**——避免与网格 I 的双重扫描）
- 组合形式：
  - 单因子：9
  - 双因子等权 AND：C(9,2) = 36
  - 三因子等权 AND：C(9,3) = 84
  - **权重向量**：对**预注册指定的 5 个候选**（f1 f2 f3 f5 f8）做权重 `w_i ∈ {0,1,2,3}`
    且 `Σw = 3` 的离散单纯形 → **35 格**（`score = Σ w_i · rank_pct(z_i)`，取 Top-K，K=20）
- `H = 5` 固定（H 敏感性只对胜出格做，见 §五.4）
- = **164 格** + 阈值固定 → **总计 164 格**

### **n_trials 申报 = 135 + 164 = 299**

## 五、冻结门槛

1. **20bp 单边成本**下事件级：`n >= 500` ∧ 超额均值 > 0 ∧ 超额中位 > 0
2. **唯一标的数 >= 30**（★177 纪律；低于此判「不可判定」，不记"未过门"）
3. 组合级（仅对过 1–2 的格）：30 相位中位夏普 >= 1.0 ∧ CAGR >= 8% ∧ 安慰剂 p <= 0.05（20 seeds）
4. **DSR >= 0.5**（deflated Sharpe，**n_trials = 299**）—— 抗过拟合主门
5. **稳健区域**：胜出格的**邻格中位数亦为正**（相邻阈值档/相邻权重）；**孤立峰判噪声**
6. 三档成本 0 / 20bp / 50bp **全报**；结果**全格上表不隐藏**

## 9.2 唯一"越过 Bonferroni"的格 = **孤立峰，判噪声**

`II|T|fr+turn+amp`：n=4,000 / uniq=545 / exc_mean **+0.72%** / **exc_med −1.09%（负）** / t **+4.81**

**两条独立证据各自足以否决**：
1. **中位为负**（−1.09%）而均值为正 ⇒ **右尾驱动**，典型交易是亏的
2. **孤立峰**：三个单因子与三个双因子子集 **全部为负**

| 子集 | exc_mean | t |
|---|---|---|
| S fr | −0.46% | −24.70 |
| S turn | −0.48% | −32.35 |
| S amp | −0.57% | −28.55 |
| P fr+turn | −0.28% | −11.02 |
| P fr+amp | −0.34% | −6.65 |
| P turn+amp | −0.00% | −0.05 |
| **T fr+turn+amp** | **+0.72%** | **+4.81** |

按 §五.5「**孤立峰判噪声**」→ **判废**。另 3 个正超额格均 t<3.1 且 exc_med 全负。

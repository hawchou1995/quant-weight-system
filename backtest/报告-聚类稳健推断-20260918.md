# 报告 · 聚类稳健推断（R-infer-0918）

> 起因：外部评审指出"148 万笔交易不能当成 148 万个独立样本"。
> 上一轮我复核后判它**方法学正确但底稿过期**，其中这一条判为「我方真空缺」并登记待建。
> 本轮建成、验证、接线。

## 一、问题是什么（说人话）

我以前判断"这个信号是不是碰巧"，是把每一笔交易当成一次独立的掷骰子来算的。
但这个假设不成立，因为：

1. **同一天的所有交易共享同一波行情**——大盘跌，当天几百笔一起跌，不是几百次独立事件。
2. **同一只票的连续信号，持有窗口互相重叠**——今天买和昨天买的，看的是同一段行情。

结果就是把"实际上只发生了几十次的事"当成"发生了几万次"，显著性被凭空放大。

## 二、建成的东西

**`factor_infer.py`（288 行）**，并已接入 `factor_gate.py` 作为第 ⑤ 项检查：

```
python factor_gate.py infer <sig.npz> [--excess] [--hold 10] [--block 20] [--B 1000]
```

它给三个以前没有的数字：
- **虚高倍数**——旧口径把真实显著性放大了几倍
- **有效样本量**——真正互不相干的样本有多少笔（不是总笔数）
- **分块重采样区间**——连续 N 天为一组重采样，保留块内相关性；概率已做加一修正，不会是 0

## 三、验证（五项可证伪验收，全过）

用合成数据做正负对照——**结论已知**，看工具能否算出来：

| 验收项 | 结果 | 判 |
|---|---|---|
| A 正对照：数据里确实有"同日共同涨跌" | 放大 **6.93 倍**（理论值 6.94） | PASS |
| B 负对照：数据里**没有**共同涨跌 | 放大 **0.97 倍**（不该检出） | PASS |
| C1 零假设：真实收益为 0、但有共同涨跌 | 旧口径 **70% 的情况下谎报显著** | PASS |
| C2 同上，用新口径 | 谎报率压回 **3.5%** | PASS |
| D 标准误对账 | 与解析解误差 **1.76%** | PASS |

**C 这一项是核心**：在真实效应为零的数据上，旧算法有七成概率告诉你"发现了显著效应"。
这不是精度问题，是**旧算法在这类数据上基本不可用**。

### 4.2 两个计划外的发现

**发现一：超额口径的虚高，远小于原始收益口径（1.2~4.0 倍 vs 1.5~13.1 倍）。**
原因：扣掉大盘基准这一步，本身就已经吸收了大半"同日共同涨跌"。
⇒ **R-tdx6b 的结论没有被推翻**——因为它在设计上就做了超额，无意中躲过了大半聚类问题。
这条经验要记：**凡是做了超额口径的检验，聚类修正量天然较小；但不等于不用做。**

**发现二（更重要）：按笔等权 与 按天等权，系统性背离。**

| 臂 | 按笔等权 | 按天等权 | 差 |
|---|---|---|---|
| B1 | **+0.013%** | **−0.641%** | 0.65pp |
| C1 | −0.194% | −0.450% | 0.26pp |
| F1 | −0.445% | −0.728% | 0.28pp |

机制：**信号同时触发越多，显示得越好。** B1 每天只出 3 笔的那些天，日均超额 −1.07%；
每天出上百笔的那些天，只有 −0.20%。三个臂方向完全一致。

⇒ **旧口径（按笔等权）系统性地比按天等权乐观 0.25~0.65 个百分点。**
⇒ 最直接的后果：**B1 勘误后那个"翻转为显著正 +0.14%"，是按笔加权的产物**——
按天算是 −0.64%，它从来没有真正翻正过。

## 三、B1 的重要保留：它的"不过门"是口径造成的，不是"没效应"

| 口径 | B1 超额均值 |
|---|---|
| 按笔（预注册口径） | **+0.013%**（≈0） |
| 按天 | **−0.641%** |
| 按天分块重采样 1000 次 | **没有任何一次均值为正**（区间 −0.84% ~ −0.43%） |
| 分年（按天） | **11 个年份全部为负** |

**机制**：B1 的效应**取决于"同一天信号同时触发多少只"**——
触发面广的日子（每天上百笔）接近中性，触发面窄的日子（每天 3 笔）显著为负。
**按笔等权把这些日子混在一起，效应被抹掉了。**

**处置（按纪律）**：**不事后换口径。** 换口径等于重新定义判据，属 config-snooping
（项目既有纪律：任何事后口径改动必须新预注册 + n_trials 申报）。
B1 仍需正式裁决的话，**另立按天口径的预注册**。

## 四、本轮暴露的两个判据缺陷（如实记录）

1. **D1 的门槛②是「不可判定」不是「不过门」**：D1 全年份笔数都 <100（最大 95），
   分母为 0。这与陷阱 ★177（阈值处样本塌缩）同类——**样本不存在 ≠ 未过门**。
   我第一版脚本输出 "0%(0/0)" 是错误呈现，已改标「不可判定」。
2. **A2 的门槛②只靠单一年份**：11 年里只有 2024 年 ≥100 笔（107 笔），
   该年按天均值还是 **+1.13%**（唯一为正的年份）。A2 的 ② 结论无信息量。

## 五、重采样概率全部触底说明

7 臂的「按天重采样负概率」**全部等于 0.0010**，即 1/(1000+1) 的**下限**。
含义是"1000 次分块重采样里没有一次均值翻正"，**不是 p=0.001**。
它只能说明**置信区间没有跨过零**，**不能用来排序强弱**（7 个臂全在下限，等于没区分度）。
——这正是外部评审提的加一修正：`p ≤ 1/(B+1)`，要让 p 更小必须增加重采样次数，
但**增加次数只是把下限压低，不会增加区分度**，判强弱仍要看效应量本身。

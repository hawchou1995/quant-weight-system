## 五、统一结论

1. **「长线切了 MA250」= 事实错误**。长线门控是 MA200，MA250 属短线 KHunter。
2. **切 MA250 是反向优化**：-114pp / 夏普 -0.231，主因 2019 年漏掉整轮行情。**不建议**。
3. **「低位稳拿」方向正确**：门控关时改为「留仓不新开」→ +97.17pp / 夏普 +0.137 / 回撤持平，分年度改善集中在 2021/2018，右尾敏感性每档均优。**建议采纳，但需过生产验收门**。
4. **「增加择时策略」= 已被 9/8 全灭**：ma_resonance / aroon / volume / mom_slope / ma_aroon 五类择时 + 弱牛分域 13 case 全部超额 < 0（n 192→27~120，2022/2023 全年无交易），根因 = v9 是右尾系统，任何额外过滤都在砍右尾。**但该批数字跑在污染数据上（9/8 21:00 前），需在干净数据上重验**。
5. **门控线本身可优化**：MA120/MA150 优于 MA200（+85~+65pp），但回撤略扩（-31.1% vs -28.7%），需权衡。

峰值在扫描下界（MA60）且「无门控」更高 → 说明这不是「存在最优窗口」，而是**越短越接近无门控**的单调退化。所谓「改短更好」实质是「门控越弱越好」，与门控存在的初衷（控制熊市风险）冲突。

即收益对门控线位置极度敏感且不稳定——参数不具稳健性。
（注：MA100/MA120 ±2 窗口区间平滑，极差 8.71~38.45pp，混沌集中在 MA60~80 下界区。）

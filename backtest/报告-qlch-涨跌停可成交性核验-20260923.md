# 报告 · 夏普虚高源核验 #1：涨跌停可成交性筛除（R-qlch-limitfill-0923）

> 对象：**全池（在产轨 B4_K3）· X4 生产口径（止25%/损30%/40日）· 3881 笔可用事件**
> 产物：`backtest/qlch_limitfill_0923.py` / `.json`（只读）
> 触发：用户要求核验「夏普 >2 是否可信」→ 本报告核验**嫌疑最大的执行层虚高源**（涨跌停不可成交未建模）

## ⓪ 结论：**排除**（本题最大嫌疑源不成立）

| 项 | 原口径 | 剔除/修正后 |
|---|---|---|
| 不可成交（模型假设） | — | **1 笔 / 3881 = 0.03%**（顺延成交 1、剔除 0） |
| 事件级单笔均值 | +9.292% | **+9.292%**（B 顺延）/ +9.303%（A 剔除） |
| 组合级夏普（20bp） | **2.750** | **2.750**（CI95 [0.226, 4.629] 不变） |
| 组合级夏普（60bp） | 2.364 | 2.364 |
| 组合级年化/回撤/笔数/换手 | +15.48% / −40.99% / 720 / 10.8 | 完全不变 |

**⇒ 涨跌停不可成交对本策略的夏普/收益几乎没有影响**：因为它是"低开低吸 + 40 日持有 + 到期按收盘平仓"的结构——入场是跳空**低开**（涨跌停买不进的情况被 band 过滤自然排除），出场多数发生在 40 日后的收盘（几乎不会恰逢封板）。

## ① 方法与判据（可复核）

| 项 | 实现 |
|---|---|
| 涨跌停价 | `round(前收盘 × (1 ± w), 2)`；`w`：主板 10% · 688/689 全程 20% · 300/301 自 2020-08-24 起 20%（此前 10%）· ST 5%（本池已剔 ST） |
| **不可成交判定** | ① **止损跳空**（模型按 `open` 卖）：`open ≤ 当日跌停价` → 开盘即封跌停 → **不可卖**；② **到期平仓**（模型按 `close` 卖）：`close ≤ 当日跌停价` → 收盘封死 → **不可卖**；③ 止损触发（按 SL 卖，价格在跌停价之上）与全部止盈类（向上有承接）→ **可成交** |
| 处置 B（主口径） | 顺延到首个 `open > 当日跌停价` 的交易日按开盘价成交（最多 5 日，仍不可则剔除） |
| 处置 A（保守上界） | 直接把不可成交事件整笔剔除 |
| 入口侧 | **天然安全**：入场要求开盘跳空 ∈ [−5%, −2%]，一字跌停（−10%/−20%）会被 band 过滤排除；涨停买不进的情况不适用于低开入场 |

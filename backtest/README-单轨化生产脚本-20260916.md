## 运行语义（关键，勿误解）

1. **T→T+1 口径**：信号日 `asof` 之后的**第一个交易日开盘**执行建仓/换仓（数据未到则等待，绝不回填信号日自身价格）。
2. **买不起一手的处理（现状行为）**：`lots = floor(min(per_amount, cash)/(px×100))`；`lots < 1 → 跳过`（打印警告）。**预算不重分配、无替补顺延**——跳过标的的资金滞留现金。量化实例（09-15 冻结清单）：轨B 18/20 只可买（90%）、轨A 8/10 只可买（80%）。
3. **轨A 为零资金对照轨**：`CAP_A=0`，仅按名义基数 17,000 记幻影净值；**不执行 pct40 出场**（保持防御基线纯净）；不出现在操作清单。
4. **pct40 出场只作用于轨B**：`backtest/pct40_exit_apply.py` 读 `satellite_paper_b.json`；`exit_control_0915.py` 已切双文件并重置对照账本（旧账本 `.bak-0915` 归档）。

## 三、缺口清单（未取到 + 原因）

1. **沪市主板简称变更 / ST 事件**（`st_events` 缺口一半）
   - `data_fundamental/name_hist.csv` **实为单名网格**（4,268,585 行里每 code 只有唯一简称，最新名日频重复到 2021-01-04~2026-06-29），无历史简称 → 原任务假设不成立。
   - 东财风险警示类报表名逐一探测（`RPT_STOCK_ST` / `RPT_RISK_WARNING` / `RPT_NAME_CHANGE` 等）→ 全部「报表配置不存在」。
   - 上交所 `query.sse.com.cn` 简称变更接口需正确 sqlId，公开入口返回错误页。
   - 备选：巨潮资讯公告全文检索（重）/ 上交所 sqlId 逆向（需浏览器抓包）。
2. **北向资金日频个股持仓（2024-08-19 之后）**：交易所层停止披露，**全市场永久性缺口**，只能退化为季度口径。
3. **`buyback_trade`（回购成交明细）覆盖仅 70-75 只**：该表为"近期回购明细"快照口径（2021+ 仅 2,544 行），不是全市场历史。建议用 `buyback_plan`（方案口径 1,390 只）替代，或改用公告文本抽取。
4. **定增预案公告日缺失**：`RPT_SEO_DETAIL` 只有实施节点（发行/上市/股权登记日），无法复现"预案公告 → 股价反应"的完整事件窗。
5. **筹码分布只有 ~1 年**：数据源限制（westock chip 回溯上限 220 交易日）。
6. **龙虎榜明细 D1~D30 收益字段**：源头自带的「未来收益」（`D1_CLOSE_ADJCHRATE` 等）、大宗交易 `CHANGE_RATE_1/5/10/20DAYS`、解禁 `A20/B20_ADJCHRATE`、席位 `RISE_PROBABILITY_3DAY` —— **已在落盘前统一剔除**，避免误入因子。

## 四、PIT 纪律执行情况

| 类别 | 做法 |
|---|---|
| 事件类（预告/快报/增减持/股东户数/回购方案/ST） | **一律保留公告日字段**（`NOTICE_DATE` / `HOLD_NOTICE_DATE` / `NOTICEDATE` / `change_date`），回测必须用"公告日 + 1 交易日"生效 |
| 交易类（龙虎榜/大宗/两融/北向/筹码） | 用发生日 `TRADE_DATE` / `date` / `HOLD_DATE`，均**当日盘后可见** → T+1 起用（两融建议 T+2，因数据约 21:00 才发布） |
| 事前已知类（解禁） | `FREE_DATE` 属事先公告日程，可直接用于未来事件窗 |
| 报告期 vs 公告日 | 股东户数 `END_DATE`（统计截止）与 `HOLD_NOTICE_DATE`（公告）严格区分；增减持 `TRADE_DATE`（发生）与 `NOTICE_DATE`（披露）严格区分；**禁止用前者对齐** |
| 事后字段 | 源头自带的未来收益/胜率类字段全部剔除（见缺口清单 6） |

## 五、下一步建议（因子测试优先级）

按「与轨B 低相关潜力 × 数据质量 × 可实现性」排序：

1. **B⑪ 解禁（未来供给压力）** —— `FREE_DATE` 事前已知，可做"过去 20 日已解禁量/流通股"与"未来 20 日待解禁量/流通股"两个对称因子；**天然与价格/量能轨低相关**，且 2027-2034 的日程可做前瞻压力。
2. **A⑤ 股东户数** —— 户数环比（`HOLDER_NUM_RATIO`）：降幅大 = 筹码集中，教科书因子，A 股实测有效，与动量相关性低。
3. **B⑦ 业绩预告** —— 预告类型 + 净利同比上下限（`ADD_AMP_LOWER/UPPER` + `NOTICE_DATE`），可复现 PEAD/预告漂移，且是**基本面轨**而非价格轨。
4. **A③ 两融** —— 融资余额/流通市值 5 日变化 + 融券余额突增（看空情绪），4.19M 行日频，横截面完整度最高（3,469 只 × 1,209 日）；注意只有 5 年样本。
5. **A① 龙虎榜** —— 用「上榜后 5 日机构/游资席位净买」构造资金持续性因子；席位明细补齐后信息量最大，但需先做席位标签（机构专用席位代码 vs 游资营业部）。
6. **B⑧ 增减持** 与 **B① 大宗交易折溢价**：事件型，更适合做风险过滤/负面清单，而非独立 alpha。

建议先跑 1+2+3 三条（覆盖"资金筹码 / 事件"两组），用现有轨B 的回测框架做 IC/分层，再决定是否补齐席位与北向。

## 七、失败清单（接口限速，非数据缺失）

`_fail_margin.txt` / `_fail_chip.txt` 记录 westock 限速失败标的（如 `sh600030`、`sh600036`、`sh600215`、`sh600227`、`sh600228`），
已在每张表落盘前执行最多 3 轮小批补漏（5 只/批 + 2.5s 间隔）；仍未成功的会留在失败清单里，属**可重跑补齐**，不是"该股无数据"。

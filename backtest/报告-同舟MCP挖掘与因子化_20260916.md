## 二、因子转化（口径强制统一）

**数据**：`fin_data__get_industry_fund_flow_series`，31 个申万一级行业 × 623 交易日（**2024-01-02 ~ 2026-09-15**），落盘 `tz_data/ff_page{1,2}.json`。

| 项 | 口径 |
|---|---|
| universe | 主板 `sh60*/sz00*`（`oss_panel_0913` 3209 只，已断言） |
| ELIG | 冻结 `asts_0916/ELIG3.npy`（成交额≥300 万、剔 ST、上市≥150 日、价>2 元） |
| 引擎 | 逐字抽取 `oss_0913/oss_super_combo_0913.py` 的 `run_engine` 段 exec；`run_engine(comp, 20, offset, slip)` |
| **基准自检** | 轨B off0 年化 **22.87%** 复现（断言硬失败保护，每阶段都跑） |
| 相位/成本 | 5 相位 0/4/8/12/16 取中位；成本 20bp（生产）/50bp（压力） |
| corr vs 轨B | 同 `run_engine` off0 日收益与 `asts_0916/base_equity_off0.csv` 对齐 |
| 行业→个股 | 本地 `stock_industry.json`（申万一级，命中 **3175/3209 = 98.9%**） |
| **PIT 申报** | 资金流为当日盘后汇总 → T 日决策用 ≤T 值；供应商若实为 T+1 汇总则当日值不可得 → **已建 `_lag1` 全序列滞后变体**做边界检验 |

**转化公式**（`flow` = 行业级 `net_inflow_to_turnover_ratio`，映射到同行业个股）：

| 因子 | 公式 | 因子可用窗 |
|---|---|---|
| `flow20` | `Σ₂₀ flow`（20 日累计净流入强度） | 2024-01-22 起（覆盖面板 44.6% 单元格） |
| `flow5` | `Σ₅ flow` | 2024-01-05 起 |
| `flow_acc` | `Σ₅ flow − Σ₂₀ flow / 4`（资金流加速度） | 2024-01-22 起 |
| `_lag1` | 上列全序列滞后 1 交易日（PIT 边界检验） | +1 日 |

**IC（全窗，rank IC 日频）**：`flow20 −0.0196 / ICIR −0.206`；`flow5 −0.0131 / −0.115`；`flow_acc +0.0009 / +0.008`；`amt20 +0.0104 / +0.068`；`_lag1` 与原型几乎一致（−0.0189 / −0.0120）→ **资金流是弱反向信号（追资金流的行业次月跑输），且发布时点不敏感**。

> ⚠️ **统计功效更正（必须申报）**：本因子在行业内是**常数**，有效独立单元 = **31 个行业**，不是 3209 只股票。按有效 N 折算，ICIR 0.206 的 t 值 ≈ 0.2×√660 ≈ 5.3，但按 31 个独立单元折算 ≈ **0.5（不显著）**。下文安慰剂正是对这一点的直接检验。

## 五、如实申报（缺口 / 前视 / 不可转）

1. **数据覆盖**：行业资金流**硬起点 2024-01-02**（实测 `start_date=2016-01-01&limit=500` 仍只回 123 日），故所有臂的"全窗"数字含 2021-08~2024-01 空仓段，**主判据取"可用窗"**（654 个交易日）。
2. **日历缺口 5.0%**：可用窗 654 个交易日中资金流缺 **33 日**（`2025-09-17/18`、`2025-11-03/04`、`2026-08-11~21`、`2026-08-31~09-04` 等），清单 `tz_data/tz_flow_calendar_gap_0916.json`；因子用 `min_periods=15` 容错 → 缺口日因子由前值近似，**属近似而非完整值**。
3. **疑似前视（禁用于回测）**：`search_backtested_events` / `get_event_backtest` 的 `backtest.returns` 是该事件的**已实现**事后收益，且**未申报收益目标标的**（`related_stock` 6~47 只、含跨行业），`cumulative_return_path` 还含 −20~0 事前段 → 任何把它当"事件后预期收益"进策略的用法都是前视。**本轮已按用户纪律标注禁用，未用于任何回测。**
4. **PIT 未申报**：`query_financial_indicators` 只有 `fiscal_year/fiscal_period`，**无公告日** → 判"PIT 不可判定"，未采用（本地 `yjbb_quarterly` 已按法定披露截止日建 PIT 面板，字段更全）。`get_kline_series` 文档明写 `adjustment=none`（未复权），而本地 `data_full` 为另一复权基准（实测同一标的价差 2~3 倍）→ **两源禁止混算收益**。
5. **需付费/额外的**：无付费墙触发；但 `get_industry_fund_flow_series` 单次 ≤10 行业、`limit ≤500`（`limit=2000` **静默返回 0 点**），全量历史需 3 页×4 批共 **12 次调用**（本会话已完成）。
6. **能力表"不可转因子"的 4 类**：定性研究框架、≤24 点短序列指标、无目标标的的事后事件收益、上游挂掉/服务端坏的 4 个工具（crowding / sector_valuation / list_supported_subjects / aggregate_similar_event_backtest）。
7. **口径陷阱（供后续使用者）**：① `detect_stock_patterns.total_change_ratio` 是**单日涨幅算术和**（共创草坪 API 50.01% vs 真实复利 61.10%）；② `screen_stocks` 的 `limit_up` **含 ST 5% 板**且不过滤 ST；③ 资金流 `limit>500` 静默失败。

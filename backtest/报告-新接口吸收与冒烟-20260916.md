## 3. 天眼查 tyc ⚠️ 部分通过（握手通、取数被拒）

**端点**：`https://mcp.tianyancha.com/v1`（streamableHTTP MCP，JSON 响应）
来源：WorkBuddy connectors `mcp.json` → `connector:tyc-mcp`

**实测**：
- 无鉴权 → HTTP 401 `{"error":"invalid_request","error_description":"missing Authorization header"}`
- `Authorization: Bearer <tianyancha.key>` → **initialize HTTP 200**：`"serverInfo":{"name":"TianYanCha","version":"1.0.0","title":"天眼查 MCP"}`
- tools/list → **17 个聚合入口**：`search_companies / search_companies_by_industry_region / search_companies_by_tag / search_companies_by_ranking / search_listed_companies / search_bids / search_patents / search_trademarks / get_company_basic_profile / get_company_group_profile / get_group_info / get_company_people / get_person_profile / get_person_risk_profile / get_company_capabilities / call_tool / call_tools_batch`
- **任何 tools/call 被拒**（原始返回）：
```json
{"error":"invalid_token","error_description":"raw OpenAPI tokens are not accepted; use OAuth or an MCP API key"}
```
- 进一步实测开放平台老网关（token 是否可用于传统 API）：
```
GET https://open.api.tianyancha.com/services/v3/ic/baseinfo/normal?keyword=9152000071430580XT
  → {"error_code":300005,"reason":"无权限访问此api"}     # 有 token；300005=无权限（未开通接口）
无鉴权对照 → {"error_code":300008,"reason":"缺少必要参数"}
```

**判定**：用户手上这把 uuid 是**天眼查开放平台（open.tianyancha.com）的 raw OpenAPI token**，MCP 网关明确不收；开放平台侧该 token 未开通任何接口权限（300005）。
**要真正取数，二选一**：
1. 到 `https://ai.tianyancha.com` 申请 **MCP API key**（或在 WorkBuddy 重新连接「天眼查」走 OAuth）；
2. 到 `https://open.tianyancha.com` 为该 token **申请/购买接口权限**（300005 消失后，`connector_tyc.py` 换端点即可复用同一套客户端）。

**脚本**：`backtest/connector_tyc.py`（已按上述实测写好；拿到 MCP key 或开通权限后直接可用）

## 6. 判词：哪些能直接为「低相关因子挖掘」供数

### 6.1 对"资金筹码 + 事件"两轴的位置

| 接口 | 资金筹码轴 | 事件轴 | 说明 |
|---|---|---|---|
| kuaicha | ✖ 无行情/资金流 | ✔✔ **强** | 司法（被执行/失信/裁判文书）、经营异常、行政处罚、股权质押、招投标、融资、舆情；且**批量筛选**可把"专精特新/高新/失信/经营异常/上市情况"直接筛成股票池 |
| qcc | ✖ | ✔（单主体） | 与 kuaicha 同源的交叉校验；只有 16 个公司基座工具，无筛选、无司法 |
| tyc | ✖ | ✔（同轴第三源） | 当前不可取数 |
| MX | ✔（行情/量比/换手/市值/PE，但**与现有 westock/东财 EM 抓取重复**） | ✔ | 增量=自然语言选股 + 研报/公告检索（含"机构参与度"类筹码文本） |
| 同舟 | ✔（K线/快照，重复） | ✔（公告/研报） | 增量=**公开因子框架/因子证据面板**（fin_graph__），需先授权 |

### 6.2 能直接供数的（可并入因子挖掘）

1. **kuaicha —— 唯一具备"批量"能力的另类基本面源**（`filter_get_enterprise_advanced_search`）
   可一次性按 50+ 维度（地区/行业/规模/成立时间/融资轮次/高新/专精特新/失信/经营异常/纳税信用）筛出企业名单，配合 `basic_get_enterprise_basic_info` 返回的 `code:["600519.SH"]` 映射到股票代码 → 构造**离散基本面/风险标签因子**（如"近一年新增被执行""专精特新新增"），与现有价格/量能因子天然低相关。
   单主体工具（工商/股东/实控人/知产/司法/舆情）用于对持仓池做**事件级补全**。
2. **MX `stock-screen` + `news-search` —— 快速铺量的截面与文本源**
   screen 返回带日期键的 PE/换手/市值/量比字段，可作为**外部截面校验**（与自算因子对表，不替代自有数据）；news-search 的研报"机构参与占比/增速/分歧"是**第三方筹码向特征**，可做事件/情绪因子，与现有新闻源（如果只有行情）互补。
3. **qcc —— 第二源校验**（同一实体用 qcc 复核 kuaicha 的实控人/股东/财务；两源不一致本身就是可用的质量信号）。

### 6.3 只是重复已有源 / 暂不可用

- **MX 行情类字段**：与项目现有 westock（腾讯自选股）、东财 EM 抓取（`fast_em_fetch.py`/`em_fetch_node.js`）、tushare、pandadata 高度重叠 → 不新建数据管道，只当**查询/校验入口**。
- **tyc**：结构性重复 qcc/kuaicha，且当前取数被拒 → 待拿到 MCP API key 再评估。
- **同舟**：行情类重复；只有 `fin_graph__` 因子证据 + 研报检索是增量 → 需用户先完成 OAuth 授权。

### 6.4 建议的下一步（不改现有生产链路，先离线试算）

1. 用 kuaicha 对三池（v9_tiers / short_pool / a5_pool）逐只拉 `orgid`+司法风险计数，落 CSV，做**事件因子的 IC 粗筛**（先验证"近 90 天被执行新增"是否与次日/次周收益有单调性）；
2. 用 MX `news-search` 按主线（AI 硬件/光通信）批量拉研报"机构参与"字段，做**文本筹码因子的时序对齐**测试；
3. tyc / 同舟两条待解锁后再补一次冒烟（同一脚本，只需换鉴权）。

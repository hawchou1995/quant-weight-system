## 0. 结论摘要

**该方法的量化复刻在 2017-01-10 ~ 2026-09-24 全区间为负期望，四闸 0/4 通过，投产建议：否。**

|---|---|---|---|---|---|---|
| 满覆盖因子组合（20bp 往返成本） | **−18.90%** | −87.70% | −1.421% | 39.0% | −2.725% | **10/10** |

三个要点：

1. **伤害不在「选板块」，在于「追放量突破」。** 赛道门单独几乎无贡献（+0.2431%/10 日 vs 全池对照 +0.3915%）；把「放量突破」叠进去立刻掉到 −0.5299%；再加上原文的「龙头」打分（资金集中/波动大/持续放量/涨幅大，行业内 z 求和取前 3）进一步掉到 −1.1807%/笔。**四个 z 分量单独排序全为负**，即「龙头」四特征在 A 股是**拥挤度/投机度代理，负 alpha**。
2. **亏损是「入场次日才开始」的持续性失血。** 入场日盘中还赚 **+0.2396%**；第 1–3 日连亏 −0.3681% / −0.3858% / −0.4231%，10 日累计 −2.19pp。持有期越长越好（H=5 −53.26% / H=10 −32.39% / H=20 −18.89%），说明负收益集中在突破后的近端——典型 A 股「放量新高后承接盘衰竭」形态。
3. **越忠实于「刚冒头」，亏得越少但仍亏。** 「20 日内首次突破」→ −0.6989%；再加「未大涨（RET20 ≤ 行业内中位）」→ −0.6100%。**12/12 参数配置全部为负**，结论对口径不敏感。

## 1. 原文 → 可量化因子映射

| 原文表述 | 量化实现 |
|---|---|
| 「从跌幅最大的板块里找」 | 行业 20 日等权收益横截面升序分位 ≤ P1(0.20) |
| 「从缩量横盘的板块里找」 | 行业 20 日波动升序分位 ≤ P2(0.30) **且** 行业 20 日/60 日均额比 < Q(0.80) |
| 「龙头＝波动幅度大」 | 行业内 z(ATR20) |
| 「龙头＝涨幅大」 | 行业内 z(RET20) |
| 「龙头＝持续放量、换手率高」 | 行业内 z(VOL5/VOL60) |
| 「龙头＝资金最集中」 | 行业内 z(成交额占比 AMT20_i / Σ_g AMT20) |
| 「每个板块选两三只」 | 全池按 F 降序取前 KNEW=3 |
| 「买点＝放量突破时 **或** 突破后第一次回踩」 | 取前一支：`close > HHV60_prev` 且 `VOL > M × VMA20_prev`（M=1.5）；回踩支在 §8 作为待测替代买点 |

> 说明：四个「龙头」特征以**行业内 z 分数之和**合成，即原文「四特征并列」的最直接量化（等价权）。

## 2. 因子计算公式

### 2.1 所需数据字段

| 用途 | 数据源 | 字段 |
|---|---|---|
| 个股日线（前复权） | `data_full/<sym>.csv` | `date, open, high, low, close, volume, amount` |
| 行业分类 | `stock_industry.json`（申万一级，version 2026-08-20） | 股票 → 行业 `map` |
| 基准 | `index_000300.csv` | `date, open, close` |

### 2.2 派生字段（信号日 t，**全部只使用 ≤ t 的数据**）

- 有效价：`Valid_t = close_t > 0`（停牌/缺失 → 无效）
- 20 日收益：`RET20_t = close_t / close_{t−20} − 1`
- 20 日均额：`AMT20_t = mean(amount | t−19..t)`（仅有效日）
- 5/60 日均量：`VOL5_t`、`VOL60_t`
- 滞后 20 日均量：`VMA20_prev_t = mean(volume | t−20..t−1)`
- 滞后 60 日最高收盘：`HHV60_prev_t = max(close | t−60..t−1)`
- 20 日振幅：`ATR20_t = mean((high−low)/close | t−19..t)`
- 有效交易日数：`NV_t = Σ_{k≤t} Valid_k`（上市满 250 日过滤）

### 2.3 行业层（30 个申万一级，等权）

- 行业日收益：`r_g(t) = mean_{i∈g, valid}( close_i,t / close_i,t−1 − 1 )`
- 行业 20 日动量：`IR20_g(t) = Π_{k=t−19..t}(1 + r_g(k)) − 1`
- 行业 20 日波动：`IV20_g(t) = std( r_g(t−19..t) )`
- 行业 20/60 日均额：`IAMT20_g(t) = Σ_{i∈g} AMT20_i(t)`，`IAMT60_g(t) = Σ_{i∈g} AMT60_i(t)`

### 2.4 赛道门（板块筛选，逐日横截面）

```
R_IR(g) = 升序分位( IR20 )        # 越小 = 跌幅越大
R_IV(g) = 升序分位( IV20 )        # 越小 = 波动越小
跌幅门     = ( R_IR ≤ P1 )
缩量横盘门 = ( R_IV ≤ P2 ) 且 ( IAMT20 / IAMT60 < Q )
Gate(g)    = 跌幅门 OR 缩量横盘门
```
实测命中：中位 **6 / 30** 个行业（均值 7.1，范围 6–14），对应合格个股中位 **646** 只（均值 744，范围 168–2,297）。

### 2.5 个股层（龙头打分）

```
SHARE_i = AMT20_i / IAMT20_{g(i)}          # 资金集中
VR_i    = VOL5_i / VOL60_i                 # 持续放量
F_i     = z_g(SHARE) + z_g(ATR20) + z_g(VR) + z_g(RET20)
```
`z_g(·)` 在行业内、以「当日通过 Gate 的合格股」为基准做标准化（`(x−μ_g)/σ_g`，该行业当日合格股 <2 只时不计入）。

### 2.6 买点与资格过滤

```
买点   = ( close_t > HHV60_prev_t ) 且 ( volume_t > M × VMA20_prev_t )     # M = 1.5
资格   = Valid_t 且 NV_t ≥ 250 且 close_t ≥ 2.0 且 AMT20_t ≥ 2×10^7 且 Gate(g(i))
候选   = 资格 且 买点
选股   = 候选按 F 降序取前 KNEW 只
```

## 3. 调仓与持仓规则

1. **信号**：第 T 日收盘后确认（所有输入 ≤ T，无未来函数）。
2. **买入**：第 **T+1 日开盘价**买入，等权。
3. **卖出**：持满 `H` 个交易日后，第 **T+1+H 日开盘价**卖出。
   - 若卖出日开盘价缺失/为 0（停牌），**顺延至下一个有效开盘价**（模拟停牌不可卖），不在净值中蒸发仓位。
4. **资金**：槽位资金 = `min(前一日收盘净值 / KSLOT, 可用现金)`；允许分数股；同一标的持仓期内不重复买入。
5. **成本**：双边，基准 20bp 往返（10bp/边），敏感性含 0bp 与 115bp 往返。
6. **净值**：**逐日收盘盯市**（`NAV_t = 现金 + Σ 持仓股数 × close_t`），full holding period 全覆盖。
7. **基准**：沪深300，**同起点同口径**买入持有。

## 7. 审计记录（本轮发现并修复的两个记账 bug）

> 这两个 bug 都**不是因子设计问题**，而是我自己的回测引擎缺陷。发现过程留档于 `p5_eventstudy.py` / `p7_reconcile.py` / `p9_coverage_census.py`。

### BUG-1｜出场日开盘价缺失导致「仓位价值静默蒸发」（严重）

**症状**：base 首跑 20bp = 年化 **−36.26%**、最大回撤 **−99.50%**、累计 −99.18%。
**根因**：旧引擎 `p4_sim_buggy_superseded.py` 中

```python
for j in [j for j, p in pos.items() if p["exit"] == t]:
    p = pos.pop(j)                 # ← 先弹出持仓
    px = O[t, j]
    if np.isfinite(px) and px > 0:
        cash += p["sh"] * px * (1 - cost_side)   # ← 只有这条路径把钱还回现金
```
出场日开盘价无效（停牌）时，持仓**已被 pop 且现金未入账** → 该仓位价值从净值中永久消失。按信号集 0.52% 的「出场日开盘缺失」发生率折算，约 6 笔 × 每笔 ≈20% NAV ≈ **−74% 净值**，足以独立制造 −99% 回撤。
**修复**：出场日开盘价无效 → **不 pop**，将 `exit` 顺延到下一个有效开盘（停牌不可卖）。
**幅度**：年化 −36.26% → **−32.39%**，回撤 −99.50% → **−98.42%**，累计 −99.18% → −97.73%。4 个持仓曾被顺延。

### BUG-2｜事件研究前向收益未保护分子 → 停牌日被记为 −100%

**症状**：分解脚本给出 V3 均值 −1.2435%、V4 −1.6337%，与独立实现的 −0.730% / −1.181% 不符。
**根因**：`FWD = O[t+1+H] / np.where(O[t+1] > 0, O[t+1], nan) − 1` 只保护了分母；出场日开盘价为 0 时 `0/price−1 = −100%`，被当成真实收益计入。共污染 **107 行**。
**算术闭合**：107 ×(−100%) / 20,666 = **−0.51pp**，与 −1.2435% vs −0.7295% 的差额 −0.514pp 精确吻合。
**修复**：分子分母同时要求 > 0，否则置 NaN。

### 交叉验证（修复后）

1. **两套独立实现精确复现**：V3 −0.7295% vs −0.730%；V4 −1.1807% vs −1.181%。
2. **逐笔记账逐位相等**：`p7_reconcile.py` 在 1,155 笔共有交易上给出 `max|事件研究 − 组合逐笔| = 0.000000 pp` → 交易记账无偏差。
3. **覆盖率归因**：`p9_coverage_census.py` 给出 `slot_full = 0`、`invalid_open = 17 (0.34%)`、**`already_held = 2097`** → 34.6% 的「未成交信号」**全部是同一标的在持仓期内重复上榜**（突破后连续创新高就一直被选中），引擎正确地拒绝重复买入；逐年覆盖率 61.9%–68.6% 均匀，**无年度构造伪影**。
4. **满覆盖口径对照**：组合单笔均值 −1.224% vs 事件研究 −1.181%（差 0.04pp）。

## 8. 忠实度讨论：我是否把文章读歪了？

原文是定性方法论，量化必然带入研究者自由度。我做了三个读法并全部回测：

| 读法 | 对原文的态度 | 单笔均值 | 结论 |
|---|---|---|---|
| ① base：放量突破 + 龙头打分 | 「买点＝放量突破时」 | −1.1807% | 负 |
| ② 「刚冒头」＝ 20 日内首次突破 | 呼应标题「刚冒头」 | −0.6989% | 负 |
| ③ 「刚冒头」+ 未大涨 | 排除已连续大涨者 | −0.6100% | 负 |

越忠实于标题的「刚冒头」，亏损收窄 40%+，**但没有一个读法转正**。因此本报告的负结论**不是**映射失真造成的。

同时须承认一处**尚未测试**的原文买点：**「突破后第一次回踩买入」**。原文把「放量突破时」与「回踩」并列成二选一；本报告只实现了前者。基于 §5.4 的路径证据（入场当日 +0.24%，次日即开始失血），**回踩买点结构上有明显改善空间，应作为下一步首测项**——但这属于新假设，不能用于反驳本报告的现有结论。

## 9. 局限性（已知且未修正）

7. **研究者自由度**：base 参数由我依原文定性表述选定（原文未给参数），存在口径选择空间；但首跑即负、修复后仍负、12/12 配置全负，说明结论对口径不敏感。

## 0. 一句话结论

1. **事件级**：K≥2 / K≥3 × 持有 N≥2 全部过四闸（基准成本 0.575%）；N=1 全灭（成本吃完反弹）。持有越长越好：K≥3·N=20 → 胜率 71.98% / 均值 +8.60% / 超额 +6.83%。
2. **「顶」离场几乎不触发**（N≤10 触发率 0.00%，N=20 仅 0.08%–0.22%）→ 本策略实际退化为**纯固定持有**。机理：顶要求"长势>80"（18 日区间高位区），底部共振标的在 ≤20 日内回不到高位区。
3. **组合口径（等权 NAV）全部为负**（CAGR −15% ~ −61%，成本最敏感）；叠加"当日共振家数≥20"市场阈值后转正（N=5：总收益 **+277.2%** / CAGR +14.9% / 回撤 −25.6% / 夏普 0.799）→ 该信号**不可连续满仓使用**，必须叠加市场宽度过滤。
4. **对照警示**：09-06 记录的见底档回测数字是**修复前旧定义**（仅 V 收复分支）的产物；当前代码（修复后含"止跌回升"分支）信号数为旧版 2.6 倍，**两套数字不可直接比**（详见 §5）。

## 3. 关键读数

- **N=1（T+1 规则下的最短持有）全档失败**：基准成本下均值 −0.59%~−0.66%（成本占往返 1.15%，吃掉全部反弹）；即使成本降到 0.2% 也只有 4/5 闸（均值 +0.16% 临界）。
- **持有越长越好，单调**：K≥2 均值 +0.43%（N2）→ +1.85%（N5）→ +3.27%（N10）→ +6.11%（N20）；K≥3 同构且更优。
- **「顶」离场不生效**（≤20 日触发率 0.0008–0.0022）；早退事件的持有分布（N=20 档：13~19 日共 24 笔 / 15585 笔）几乎可忽略。**若沿用该策略，等于只买"固定持有"**。
- **NAV 口径的负值来源**：等权重叠篮子在 2016-12-12 / 2018-01-29 / 2018-12-10 / 2024-02-05 / 2025-04-07 / 2025-11-07 等**千股级暴跌日**吃满高 beta 暴露（单日均值 −7%~−10%），事件级正期望被少数极端日的连续暴露蚕食。**这不是 bug**：家族自己的 见底[-25,-20] 档同方法下 NAV total 亦为 −97%（`heima_jiandi_regime_0906_out/jiandi_opt_grid_0906.csv`）。
- **成本极敏感**（事件级 + 篮子级都是）：0.575%→0.2% 使 K≥2·N=5 均值翻 1.4 倍、NAV CAGR 从 −36.8% 收窄到 −16.6%。

## 5. 复现校验与数据发现（重要）

1. **09-06 对照组 vs 当前代码（信号定义版本差异）**：上穿三档计数与 09-06 记录一致（21978 vs 22257、8599 vs 8743、3873 vs 3992，差 ≤3%）→ 数据缓存基本未变；但**见底档**：用"修复前"逻辑（仅 V 收复分支）复算 = 8510 ≈ 09-06 记录的 8618，而**当前修复后代码 = 22382（2.6×）**。结论：**09-06 的 `jiandi_signal_0906.csv` 与 `jiandi_opt_grid_0906.csv` 是修复前定义的产物**；当前代码含 2026-09-06 的"止跌回升"分支修复（该分支此前恒 False）。**两套数字不可直接对比**；本报告全部采用**当前（修复后）定义**。
2. 复现家族单元格（见底档, thresh≥3, H=5）：当前定义下 n=21406 / NAV total −87.77% vs 记录 7819 / −75.51% —— 同向同量级，差异全部归于第 1 条定义版本（NAV 方法逐行对齐家族实现）。
3. **数据质量**：v8_factor_cache 存在 **393 行 0 价占位（open/close）**，集中在 2026-08/09 尾部（近期停牌/退市股）→ 已加价格有效性门控（丢弃 112 个受影响事件）；建议上游把 0 价改为缺失值，否则连续记账型指标会被污染。
4. 《高点警示》「顶A/风险区」（PEAKBARS）为未来函数类，未纳入回测（作者原文亦标注该函数为波峰回溯）。

# PRE-REGISTRATION · 超跌策略牛熊分域 + 择时门（R-sharesweb-0921c）

> 上游：`报告-sharesweb方向改造-超跌假设成立未达门-20260921.md`
> 用户 2026-09-21 提问：牛熊表现差异很大（牛 +0.035% vs 熊 +0.151%），加牛熊分域？加择时？都加？

## 一、动机与已知风险

上游已确立：A2 超跌 `ret20(T-1) ≤ -7.31%` 是 FDR 校正后唯一存活的方向族，
单笔净 20bp +0.103%、安慰剂 5.0σ、分年 8/9 正。**但唯一致败的 2026 是样本最大年（4,248 笔，−0.260%）。**

牛熊读数差 4 倍：牛 +0.035% vs 熊 +0.151%。若 edge 只存在于熊市，则"只在熊市交易"可能同时改善
单笔收益与回撤——这是本轮要检验的假设。

**已知风险（必须披露）**：
1. "熊市更好"是本轮在样本内发现的，**属于事后选择**。牛熊定义（HS300 vs MA20）是项目既定口径、
   非拟合，这部分不含窥探；但"因此只在熊市交易"这个决策含窥探。
2. 2026 年是熊市占多数（81 牛 / 93 熊）却仍然亏损 → **熊市分域未必能救 2026**，这是本轮的关键检验点。

## 二、口径冻结

- 面板 `panel_kv_0913.npz`，2604 天 × 4087 主板，2016-01-04~2026-09-18，含退市
- 共有滤网：C1 非ST / C2 流通市值 50-200 亿 / C3 量比≥1.2 / C5 换手率 5%-10%
- 基础臂：**A2 超跌 ret20(T-1)≤-7.31%**；**A2g = A2 + T+1 开盘 gap∈[−5%,−2%]**
- 成本：往返 20bp / 50bp 双档；执行 T 收盘确认 → T+1 开盘买 → T+1 收盘卖，满仓复利
- 牛熊定义：**HS300 收盘 vs 其 MA20**（项目既定，`short_pool.market_gate` 同口径），牛 = close≥MA20
- 择时门全部用**当日收盘可算**的量，信号日 T 判定，T+1 执行（无前视）
- FDR：Benjamini-Hochberg，n_trials 申报
- 安慰剂：同轮廓 20 seeds
- **训练/测试拆分**：2016-2021 定义规则 → 2022-2026 只跑一次（防 regime 选择窥探）

## 三、臂设计（n_trials = 11）

### 第一层 · 牛熊分域（4 读数，非独立臂）

| 读数 | 内容 |
|---|---|
| A2-牛 | A2 且当日为牛市 |
| A2-熊 | A2 且当日为熊市 |
| A2g-牛 | A2g 且当日为牛市 |
| A2g-熊 | A2g 且当日为熊市 |

### 第二层 · 择时门（4 臂，基础 = A2）

| 臂 | 门条件（T 日收盘） | 设计意图 |
|---|---|---|
| T0 无门 | — | 对照 |
| T1 熊市门 | HS300 < MA20 | 只在熊市交易 |
| T2 乖离门 | HS300/MA20 − 1 < −2% | 指数本身超卖（全窗 18.6% 的交易日） |
| T3 双重弱门 | HS300 < MA20 ∧ MA5 < MA20 | 短中长期同步走弱 |

### 第三层 · 都加上（3 臂，基础 = A2g）

| 臂 | 门条件 |
|---|---|
| C0 无门 | — |
| C1 熊市门 | HS300 < MA20 |
| C2 乖离门 | HS300/MA20 − 1 < −2% |

## 五、预设退出

1. 2026 在任何分域/门下仍为负 → **判"edge 已衰减"，不投产**，转 Candidate 观察
2. 50bp 仍全灭 → 不投产（成本墙未破）
3. OOS（2022-2026）不过 → 判为样本内 regime 拟合，不投产

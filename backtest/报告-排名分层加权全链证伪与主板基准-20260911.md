## 五、零假设检验（修正版 → 扩样钉死）

- 设计修正：RANKW-3 只随机化 `cand.sort`，但买入循环 `sorted(pb, key=-score)` 二次排序仍按分数买头部 → 无效零假设；修正版（RANKW-4）乱序**两个**注入点（候选排序每期换种子 + 买入循环恒等序），结构完全保留 zerohead5。
- **族 A（N=70，seeds 1000–1069）**：mean −21.6% / std 36.48% / med −29.37% / max **+143.28%**；8/70 ≥ real → **单侧 p=0.1268（不显著）**；real 分位 88.6%；**max-gate FAIL**。
- **族 B（pool=6000）**：v2 N=30 → p=0.1935（mean −4.29% / max +144.09%）；**扩样 +100 seeds（2030–2129）→ 合并 N=130**：26/130 ≥ real → **p=0.2061（不显著）**；分布 mean −8.75% / std 42.41% / med −16.09% / min −75.16% / max **+156.57%** / p90 +50.15% / p95 +67.38% / **30.0% 随机臂为正**。
- 下尾检验（镜像头臂 −57.22%）：**9/130 → p=0.0763**（头臂劣于随机：方向支持、未达 5%）。
- → **「剔除头部持中段」+16.78% 无法排除运气，判为统计假象**（三口径 p 全数 > 0.12；随机臂最大 +156.57% 远超 real）。

## 六、基准独立核验（回答「为什么这么多人炒股」）

| 基准 | 口径 | 数值 |
|---|---|---:|
| HS300 | 2016-01-04 → 2026-09-11（3469.066 → 4510.16，`check_hs300.py` 独立复算） | **+30.01%**（CAGR≈2.5%） |
| 主板全池 B&H（严格） | 全程存续 n=2294、等权 | 均值 **+19.33%** / 中位 **−26.69%** / 正收益占比 **34.1%** |

- **语义澄清**：本项目证伪的是「v9 特定引擎」与「技术面信号族」（追涨/抄底/RS/打板/KDJ…），**不是主板 beta**。
- 同一份口径下**中位 −26.69%、仅 34.1% 为正**（存活口径、带向上偏差）→「炒股的人多」与「大多数人难赚钱」不矛盾；指数正收益由少数权重股与右尾贡献。
- 三个结构性事实：① 交易成本持续扣血；② 右尾依赖（Z5 top5% 交易贡献 1309%，多数交易是磨损）；③ 幸存者偏差（「炒股赚钱的人」是被筛选后的可见样本）。
- 能赚钱的路径已被本项目验证存在：**基金动量轮动 FB3-H20**（夏普 1.316 / 总收益 733.38% / 741 笔 / 胜率 68.0%）——基金系统化配置，不是「炒股」。

## 七、结论

1. **v9 股票中长线：维持零生产变更**——RS 闸门（8 组全负）、排名分层加权（20 臂全负 + 转正臂三重证伪）均救不回；根因在选股本体。
2. **排名分层加权：否决，独立研究线关闭**；「排名头部 = 负信息」（74pp 头尾差，扩样下尾 p=0.0763 方向支持）为干净结论。
3. **口径澄清**：证伪对象是 v9 引擎与信号族，非市场 beta（HS300 +30.01%）。
4. 唯一待拍板：**基金池持仓周期 10 日 → 20 日**（FB3-H20 回测证据，需用户拍板）。

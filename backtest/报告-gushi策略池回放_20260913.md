## 四、判读（如实）

1. **有正料**：9 个策略里 6 个在"T+1 开盘买入→T+1 收盘卖出"口径下为正超额（+0.8~1.6pp/次），竞价阿尔法/T+1闪电/早盘之星最强；扣双边成本（约 0.15%）后仍有约 +0.3~1.4pp/次的薄利。
2. **但样本太薄**：仅 11 个交易日、单一市场状态，t=1.89 不显著，逐日方差极大（单日 −4.9% 出现过）——**不能作为投产依据**。

4. 共振选股页的 12 因子当日表现普遍为负——与"追热点"一致，不作入场使用。

## 七、A 方案落地：每日自动采集（自愈式，已并入收盘链）

**通道（双通道自动兜底）**：`backtest/gushi_daily_collect.py`
- **首选 9223 = 专用自动化 profile**（`D:\Tools\chrome-auto-profile`，独立窗口，**自己登录、自己跑，绝不动用户平时用的浏览器**）；离线时自行拉起，采集完**自动关窗**不留残窗（`--keep-open` 可留）。
- **备选 9222 = 用户本人的 Chrome**（真实 profile 经 junction `D:\Tools\chrome-profile-link` 绕开 Chrome 152 调试封锁）——**只借用，永不拉起/重启**。
- 通道判定**以「是否真的取到数据」为准**（不是「谁先在线用谁」）：先试在线通道，全失败才拉起自动化 profile 重试，故「用户浏览器在线但未登录」不会挡住已登录的自动化通道。

**挂载方式**：已并进 `daily_refresh.py` 末尾的**非致命步骤**（解释器自动探测 websockets；失败/离线/未登录都不阻断主链），因此由既有自动任务 `automation-999fea3b`（每交易日 15:30）自动带跑，无需新增定时任务。

**自愈语义**（关键设计）：
- 每次运行先算「最近 N 个交易日（默认 5；**收盘链里用 10**）里缺失的日期」，只补空缺，不重复写；跨目录识别 `raw/`、`raw_vip/`、`daily/`，历史 11 天不会被重采。
- **站点窗口钳制**：服务端硬限「最近 15 天」（**VIP 同样受限**），其 `earliest_date` 从 403 响应里自动缓存到 `gushi_data/window.json`；比它更早的日期**不再重试**（否则每次都会对窗口外日期空跑）。
- **取不到数据就不落盘**：该日期保持“缺失”状态，下次运行自动重试——浏览器没开、非交易日、会话掉线都不会造成空洞，也不会留下空占位文件。
- **归因不误报**：全部待采日期都返回 403 时判为「窗口外」（`[info]`），只有真正取不到数据才报登录异常（此前会把「窗口外」误报成「登录失效」，已修）。
- 一次页面会话批量取回多日数据（省 Cloudflare 挑战次数）。

**数据集读取口径**：新增 `backtest/gushi_picks.py`（`load_picks()` 合并 `picks_0913.jsonl` + `picks_daily.jsonl`，按 日期/类型/策略/代码 去重）。旧分析脚本口径原样未动；**后续重跑推断/审计请走该读取器**，累积样本会自动进入。

**登录态（已解决，且后续可自主补登）**：用户已在自动化窗口登录完成 → 实测 `/api.php?action=me` = `{role:"vip", group:"VIP 会员", user:"HawChow"}`。**我的上轮判断（“必须人工登录”）表述过头了**：自动化 profile 里的 **Google 会话是热的**（新标签访问 `myaccount.google.com` 直接载入账号页、未跳登录），因此 LINUX DO → Google 这条 OAuth 链是纯点击流，**会话若再过期，我可自行补登**，无需再麻烦用户（仅当 Google 会话本身失效时才需要人工）。

**历史可得性结论（实测硬证据）**：`factor-stocks&date=2026-08-24` → `{"code":403,"msg":"策略选股仅允许查看最近 15 天（2026-08-28 至 2026-09-11）","result":{"strategy_history":{"days":15,"custom":true,"limits":{"min":1,"max":3650},"earliest_date":"2026-08-28","latest_date":"2026-09-11"}}}`——`limits.max=3650` 只是声明未生效，**VIP 也拿不到更早历史**，11 个交易日即当前上限；故本采集器的价值 = **从 2026-09-14（周一）起逐日累积**。

**验证证据（实测输出）**：通道实测 = 「试 9223 vip → 未取到 → 试 9222 guest → 未取到 → 拉起/关窗」，用户浏览器全程未被触碰；`--days 20` 在窗口缓存后 **0.465s 秒判「数据齐全，无需采集」**（钳制生效）；强制窗口外日期 `--date 2026-08-20` → `[info] … 全在站点可查窗口之外（403）` + 末尾「窗口内数据齐全，无需补采」（归因修正生效）；`gushi_picks.load_picks()` = 971 条 / 11 个交易日。

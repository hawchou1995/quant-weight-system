## 六、⚠️ 发现的既有缺陷（**非本轮引入**，未动手修复——按纪律只报不动）

**症状**：短线「股票池/基金池」两张在用表格的四类联动功能**静默失效**：
① 详情卡片不随搜索/板块/行业/档位筛选联动；②「只买」按钮失效；③ 表头排序后卡片不重排；④ 行/卡片点击不弹详情。

**根因**：`build_dual_system.py` 的联动接线块（2026-09-03 引入）循环 `['tbl-v9','tbl-short-stk','tbl-short-fund']`，
但 **v9 表格已于 09-13 退役移除**（`tbl-v9` 元素不存在）→ 循环第一个 id 即命中
`line 3096: table.querySelectorAll(...)`（`table=null`，缺空值保护）→ 抛出 → **整个 forEach 中止**，后两个 id 的接线全部跳过。
（该异常为静默 uncaught，仅控制台可见，页面其余部分不受影响。）

**直接证据**（本机渲染实测）：`tbl-v9` 不存在（`MISSING_IDS tbl-v9:0`）；基金表搜索 'zzz__none' 后**卡片仍 3 张**（`cardLinkAlive:false`）；

## 八、教训（已入 traps）

- Basic 认证站点的浏览器化验证：URL 内嵌凭据 → 页面内 `fetch` 被 Chrome 拦（"URL that includes credentials"）→ 必须用
  `Network.setExtraHTTPHeaders` 注入 `Authorization` 且 URL 保持干净；页面有免责声明弹层需先点击再截图。
- 大段 HTML/JS 注入 f-string 模板（build_dual_system.py）时，把内容作为**独立模块字符串**用 `{VAR}` 占位符注入，
  可完全绕开 `{{}}` 双写陷阱（本次 7 处补丁零转义问题）。

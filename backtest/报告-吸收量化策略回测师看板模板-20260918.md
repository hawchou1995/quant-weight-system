## 二、模板架构（值得吸收的部分）

```
回测脚本 → report_data(JSON) → dashboard_template.html → 自包含 HTML
```

**注入方式**（3 个占位符）：`__REPORT_TITLE__` / `__HTML_LANG__` / `__REPORT_DATA__`
（JSON 里的 `<>&` 必须转义为 `\u003c` 等，防破坏 HTML）

**`report_data` 关键字段**：
- `meta`：strategy_name / symbol / start / end / initial_cash / final_value / market
- `summary`：total_return_pct / annual_return_pct / max_drawdown_pct / sharpe / win_rate_pct / total_trades
- `equity_curve` / `pnl_curve` / `drawdown_curve`（后两者由前者派生）
- `trade_history`：symbol / side / entry_date / exit_date / holding_bars / entry_price / exit_price / pnl / pnl_pct
- `ui`：tabs / language(zh,en) / **color_scheme（eastern 红涨绿跌 / western 绿涨红跌）**
- **`modules[]`：声明式模块数组** —— `overview_chart` / `metric_table` / `trades_table` / `line_chart` / `text` / `custom_html`

**中文标签（`dashboard_locales.py` 逐字）**：
- 页签：总览 / 绩效 / 交易分析 / 交易明细
- KPI：累计盈亏 / 最大权益回撤 / 交易次数 / 事件数 / **胜率** / **夏普比率** / 累计事件收益 / 平均收益 / 中位数收益
- 绩效表：净利润 / 累计事件收益 / 平均收益 / 中位数收益 / **年化收益** / **最大回撤** / 交易次数 / 事件数 / **胜率** / 最大单笔 / 最小单笔 / 期末权益
- 图表开关：权益曲线 / PnL曲线 / 回撤 / **买入持有** / 买卖点；绝对值 / 百分比
- 交易明细列：标的 / 事件 / 方向(多空) / 开仓日 / 平仓日 / 持有Bar / 数量 / 开仓价 / 平仓价 / 盈亏 / 盈亏%

⇒ **整个标签表零内部术语**（无 t值 / IC / uniq / bp）——与项目 0918 定的「人话口径」完全同向。

## 四、⚠ 吸收必须打的一个补丁（否则数字静默出错）

**插件的 `_load_summary_json` 期望嵌套格式 `{"summary": {...}}`，而项目的 summary 文件是平铺的**
（顶层直接是 `total_return_pct` 等）→ `payload.get("summary", {})` 取到空字典 →
**插件用自己从净值曲线重算的值静默覆盖你的数字**。

**实测后果**（未打补丁时）：

| 指标 | 项目原值 | **插件静默给出** |
|---|---|---|
| 年化收益 | 11.79% | **13.95%** |
| 夏普 | 0.959 | **1.102** |
| **胜率** | **64.7%** | **0.0%** ← |
| **交易笔数** | **465** | **0** ← |
| 最大回撤 | 16.47% | 16.47% |

**打法**：把平铺 JSON 包一层 `{"summary": {...}}` 即可（本报告交付的适配器已内置，实测修复后逐位还原）。

## 十、CDN 本地化（已落地，2026-09-18 21:0x）

**问题**：插件模板引用 2 个 CDN（`marked@14.1.2` + `dompurify@3.1.6`）→ 离线/内网环境下，
`text` 与 `custom_html` 两类模块无法渲染。项目既有实践本就是本地化（`echarts.min.js` 早已落地）。

**做法**（**不改插件任何文件**）：
1. `curl` 下载两个库到 `backtest/assets/`（实测 **HTTP 200**；版本自证：DOMPurify 3.1.6 / marked v14.1.2 均在文件头）
2. `看板模板本地化.py`：读插件模板 → 把 2 个 `<script src>` 换成**内联** `<script>` → 落项目本地副本
   （安全校验：两个库均**不含** `</script>`，可安全内联；产出后断言**零 CDN 残留**）
3. `看板渲染.py` 优先使用本地化模板；无则退回插件模板并打印提示

**验证证据**：

| 项 | 结果 |
|---|---|
| 本地化模板 | `assets/dashboard_template_local.html` **155.0 KB**，**残留 CDN 0 处** |
| 产出 HTML | `_tmp_dash_local.html` **570.9 KB**（比带 CDN 的 514 KB 多出的 **57 KB 正是内联的两个库**） |
| **外部引用** | **无 ✓ 完全自包含**（正则扫 `src/href="http..."`） |
| 内联库标记 | marked ✓ / dompurify ✓ |
| 6 个关键数值 | 82.99 / 11.79 / 16.47 / 0.959 / 64.7 / 465 **全部在页内** ✓ |

**产物**：`backtest/看板模板本地化.py`（可复现构建器）/ `backtest/assets/{marked-14.1.2.min.js, dompurify-3.1.6.min.js, dashboard_template_local.html}`

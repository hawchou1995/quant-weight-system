## 三、出入场规则（改后完整规格）

### 入场（**未改动**）
1. **信号日 T 的候选池**（在产轨 = **全池** B4+K3，剔北交所）：
   非ST ∩ 量比 ≥ 1.2 ∩ **B4 分位带**（流通市值分位 ∈ [.20, .70] ∩ 换手分位 ∈ [.40, .80]）∩ **超跌** `ret20(T−1) ≤ −7.31%` ∩ **熊市门** `HS300(T) < MA20(T)`
2. **入场日 T+1**：跳空 `gap = open(T+1)/close(T) − 1` **必须落在 [−5%, −2%]**（即开盘价落在 `[0.95, 0.98] × 信号日收盘`）→ **成交价 = 当日开盘价**
3. **仓位**：K=3 硬槽位 · 单票目标权重 = 当日净值 × 1/3 · 现金约束不加杠杆 · 满槽不发新单 · 同日多信号按固定种子随机取

### 出场（**本次改动**）
| 项 | 旧（X0） | **新（X4）** |
|---|---|---|
| 止盈 TP | +15% | **+25%** |
| 止损 SL | −20% | **−30%** |
| 最长持有 MAXHOLD | 20 交易日 | **40 交易日** |
| 同 bar 优先级 | 跳空SL > 跳空TP > 日内SL > 日内TP | 同（未改） |
| 跳空成交 | 按当日 open 成交 | 同 |
| 到期 | 入场日起满 MAXHOLD 个交易日（含入场日）按收盘平仓 | 同（周期改为 40） |
| T+1 | 入场日不可卖（最早次日） | 同 |
| 成本 | 往返 20bp（`COST_RT=0.002`，无滑点） | 同 |

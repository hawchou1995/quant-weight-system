## 一、⚠ 权重 bug：上一轮全部数字作废

上一轮（`_tmp_0922_gaterank.py`）的组合权重写成：

```python
w = 1.0 / max(len(lst), K)     # lst = 当日「全部候选」，如 20 只
```

**只买 K=3 只，却按 20 只摊权重 → 实际只部署 3/20 = 15%。** 正确写法（`_tmp_0921_poscap.py` 与本轮）是
`1.0 / max(len(sel), K)`（`sel` = 选中的 K 只）→ 100% 部署。

**后果**：上一轮所有夏普/年化被系统性压低，且**压低程度随「当日候选数」变化**——而候选数与门相关
（无门候选更多）→ **门的对比也被污染**。

**处置：上一轮 `报告-qlch熊市门与TopK排序-20260922.md` 的 §一/§二 全部数字作废**，以本报告为准。
作废的那些读数不计入 n_trials（修正 bug 不等于新试验）。

## 二、实验 A · 门的配置交互（2×2×2 因子，训练窗，20bp）

**门的增量 Δ夏普 = 夏普(无门) − 夏普(MA20)，同格对比：**

| 滤网 | K | MA20 夏普 | 无门 夏普 | **Δ夏普** |
|---|---|---|---|---|
| 绝对 | 无 | 0.894 | 1.018 | **+0.124** |
| 绝对 | 3 | 0.920 | 1.094 | **+0.174** |
| 分位 | 无 | 1.774 | 1.840 | **+0.066** |
| 分位 | 3 | 1.685 | 1.868 | **+0.183** |

**四格 Δ 全部为正 → 门的增量与配置无关（同号），不存在"配置交互"**。
原以为的"交互"是权重 bug 的产物。

**门周期本身（MA20 vs MA200/MA250）**：MA20 大幅胜出（Δ夏普 −0.950 / −0.987）→ **我当初未验证选的 MA20 被数据支持**。

**但门的存废取决于成本档：**

| 配置 | 训练窗 20bp 夏普 | **50bp 夏普** |
|---|---|---|
| MA20 + 随机 | 1.685 | **1.034** |
| 无门 + 随机 | **1.868** | 0.992 |
| MA20 + 综合分Top3 | 1.805 | **1.157** |
| 无门 + 综合分Top3 | **2.002** | 1.143 |

**20bp 下无门胜（+0.183），50bp 下 MA20 胜（+0.042/+0.014）。** → **成本档依赖 → 判「不确定」→ 保持 MA20**
（MA20 也是风险控制；且它在压力档更优）。

## 三、实验 B · TopK 排序（修正权重后，**结论与上一轮相反**）

| 排序键 | 训练窗夏普 | 训练窗年化 | 训练窗回撤 | vs 随机 | 判定 |
|---|---|---|---|---|---|
| 随机（现状） | 1.685 | +24.20% | −13.98% | — | — |
| 超跌深度 | 1.597 | +23.16% | −13.11% | −0.088 | ❌ |
| gap 深度 | 1.822 | +26.83% | −14.14% | +0.137 | ❌（回撤劣化 0.16pp） |
| **综合分**（z(ret20)+z(gap)） | **1.805** | **+26.13%** | **−11.97%** | **+0.120** | **✅ 过门** |

**综合分 Top3 同时改善夏普（+0.120）与回撤（−13.98% → −11.97%，改善 2.01pp）**，50bp 档亦改善（1.034 → 1.157）。

**可执行性**：两个分量在 T+1 开盘下单时刻全部已知（ret20 为 T-1 收盘，gap 由 T+1 开盘价算出）→ **无前视**。

**上一轮判"三键全否"是 bug 造成的。** 修正后 `综合分` 是有效排序维度。

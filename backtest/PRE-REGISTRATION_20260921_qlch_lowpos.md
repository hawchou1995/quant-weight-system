## 三、信号定义（新臂 = 低位前置 + 突破）

四要件，全部尾随、T 日可算：

| 要件 | 定义 |
|---|---|
| D1 长期下行 | `close(T-120)/close(T) - 1 >= 0.20`（现价低于 120 日前至少 20%） |
| D2 低位 | `pos60 = (C - min60)/(max60 - min60) < θ_pos`，θ_pos ∈ {0.10, 0.20, 0.30} |
| D3 底部横盘 | 平台窗 W 日（结束于 T-7，严格排除试盘窗）内 `(max-min)/min <= 0.25`；W ∈ {20, 40, 60} |
| D4 突破 | `C(T) > 平台高 × 1.005` ∧ `C(T) > O(T)`（收阳）∧ `vr(T) = amount(T)/mean120(amount) >= θ_vr`，θ_vr ∈ {1.5, 2.0, 3.0} |

**对照臂（本体）**：gushi206 主臂 S1 横盘(40日结束于T-7，宽度≤25%，静默度≤4%) → S2 试盘(t0∈[T-6,T-2]，vr≥2.0，涨幅∈[0,9.5%]，上影≥0.15) → S3 洗盘(缩量≤试盘日×0.9，不破试盘日开盘×0.95) → S4 突破(C>平台高×1.005，vr≥1.5，收阳)。

## 四、试验设计（单维度扫描，禁止全交叉）

全交叉 3×3×3×2 = 54 组 → 多重检验淹没信号。**改为单维度扫描**：固定基线，每轮只变一个维度。

| 扫描 | 变维度 | 组数 |
|---|---|---|
| S0 基线 | 固定 θ_pos=0.20 / W=40 / θ_vr=2.0 / 缩量前置=有 | 1 |
| S1 | θ_pos ∈ {0.10, 0.20, 0.30} | 3 |
| S2 | W ∈ {20, 40, 60} | 3 |
| S3 | θ_vr ∈ {1.5, 2.0, 3.0} | 3 |
| S4 | 缩量前置 ∈ {有, 无} | 2 |
| **合计** | | **12 组** |

**n_trials = 12（申报）**，FDR（Benjamini-Hochberg）校正；另加对照臂 1 组，共 13 个读数。
判据以 **FDR 校正后 q < 0.10** 为准，未校正 p 仅作参照。

1. **唯一同时命中「规则清晰 + 口径可复现 + 本地数据齐」的项目是 `zhuleimed/etf-daily-sync-and-backtest`**（21★，2026-09 活跃）：44 个策略子目录（`ls -d strategies/*/ | wc -l`）、统一成本模型（佣金万2双边 + 滑点万1 + 冲击成本）、统一 look-ahead 修正（信号 close[T-1] → 执行 open[T]），且作者**主动公开了自己踩的 look-ahead 坑**（HS300 MA10 从 +320.6% 修正到 +1.8%），口径可信度显著高于同类。

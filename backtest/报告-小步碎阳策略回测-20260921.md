## 七、⚠ 容量门（★196）—— 这是本策略最大的问题

```
信号密度：236,769 笔 / 2,579 个活跃日 ≈ 92 笔/日
持仓中位：23 日
⇒ 平均并发仓位 ≈ 92 × 23 ≈ 2,100 个
⇒ 17 万本金下每仓 81 元 → 佣金最低 5 元 = 620bp/单边
```

**上面所有成本档（20bp / 50bp）都建立在「单笔规模足够大」的隐含前提上**，
而全市场等权铺开时这个前提不成立 —— 真实成本是本表假设的**30 倍以上**。

结论：**该信号只能取子集执行**（例如每日最多 N 只、并发上限 20，则每仓 8,500 元 → 佣金约 6bp/单边，
20bp 档才站得住）。**取哪 N 只，需要另立预注册的排序键**（本报告未做，不事后挑选）。

### 17.7 新陷阱（本轮第二次同类错误）

**陷阱 ★（对照统计的极值方向）**：`Δ回撤 = 回撤 − 基线回撤` 这类**带符号的改善量**，
在取「随机能达到的最好水平」时必须取 **max**（数值最大=最接近 0=改善），
写成 `max(−min)` 就把**最差抽样**当成了最好 —— 门槛被抬高 ~14pp，结论直接反向。
**与同轮 `gate1` 的 `<=` 同类：都是"改善"的方向定义错。**
**规程**：① 任何改善量先写明「变大=改善 / 变小=改善」；② 极值取用前用小样本自检（本次若用 3 次对照手算即可发现）。

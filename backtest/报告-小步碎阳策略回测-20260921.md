### 结论

1. **出场规则有效**：相对固定 20 日（扣大盘 +0.27%），X2 / X8 把每笔超额提到 **+0.58~0.62%**，
   按天 t 值翻倍到 **9.0 / 10.6**；**且只有它们在 50bp 压力档仍为正**（基准档为 −0.23%）。
2. **爆量阈值用 3× 比 2× 好**（X2 +0.62% > X1 +0.45%）：2× 触发太频繁（79% 靠规则出场）→ 砍早了。
3. **你的破线止损单独用是负贡献**（X4：扣大盘 +0.19%、50bp 后 −0.31%、胜率仅 34.9%）
   —— 持仓中位被砍到 16 天，常在震荡里被洗出去。**与爆量规则并列时也是拖后腿**（X5 +0.31% < X1 +0.45%）。
4. **「爆量后第二天」取「次日」比取「后第二日」好**（X5 +0.31% > X6 +0.26%）。
5. **入场臂敏感性**：换 `B_fixed` 入场，X5 超额 +0.28%（t 8.02）vs `A_tdx` +0.31%（t 7.57）
   → TDX 原文口径略优，但差异很小（量能/年线约束贡献有限）。

## 七、⚠ 容量门（★196）—— 这是本策略最大的问题

```
信号密度：236,769 笔 / 2,579 个活跃日 ≈ 92 笔/日
持仓中位：23 日
⇒ 平均并发仓位 ≈ 92 × 23 ≈ 2,100 个
⇒ 17 万本金下每仓 81 元 → 佣金最低 5 元 = 620bp/单边
```

**上面所有成本档（20bp / 50bp）都建立在「单笔规模足够大」的隐含前提上**，
而全市场等权铺开时这个前提不成立 —— 真实成本是本表假设的**30 倍以上**。

结论：**该信号只能取子集执行**（例如每日最多 N 只、并发上限 20，则每仓 8,500 元 → 佣金约 6bp/单边，
20bp 档才站得住）。**取哪 N 只，需要另立预注册的排序键**（本报告未做，不事后挑选）。

### 10.3 自查：一个被我修掉的成本 bug

首版无限资金模拟把「每笔名义」当成 **1 手(100 股)** 计佣金最低 5 元 → 50bp/单边，
比真实（每仓 8,500 元 → 5.9bp/单边）多扣约 **90bp 往返**，使 X2 从 **+4.90% 变成 −1.95%**（符号翻转）。
修正为「每仓名义 = NAV0/20 = 8,500 元」后得本表数字。**教训：成本模型里「名义规模」是隐式假设，必须显式声明。**

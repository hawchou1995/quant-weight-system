## 七、⚠ 容量门（★196）—— 这是本策略最大的问题

```
信号密度：236,769 笔 / 2,579 个活跃日 ≈ 92 笔/日
持仓中位：23 日
⇒ 平均并发仓位 ≈ 92 × 23 ≈ 2,100 个
⇒ 17 万本金下每仓 81 元 → 佣金最低 5 元 = 620bp/单边
```

**上面所有成本档（20bp / 50bp）都建立在「单笔规模足够大」的隐含前提上**，
而全市场等权铺开时这个前提不成立 —— 真实成本是本表假设的**30 倍以上**。

结论：**该信号只能取子集执行**（例如每日最多 N 只、并发上限 20，则每仓 8,500 元 → 佣金约 6bp/单边，
20bp 档才站得住）。**取哪 N 只，需要另立预注册的排序键**（本报告未做，不事后挑选）。

## 十三、排序键 × 仓位回收消融（XBSY-ABL-0921）—— 修正第十二章的归因

预注册：排序键 5 档（量比升序 / 量比降序 / 成交额升序 / 随机 / 代码序）× 出场上限 3 档（250/60/20）
× 入场臂 3 条（B 缩量大跌甲 / C 越跌越缩乙 / D 共振后10日）= **45 格**，固定 20 仓。

### 13.2 排序键方向一致性（同一 key 在 3 个臂上的 cap=250 年化）

| 排序键 | B 缩量甲 | C 越跌越缩 | D 共振后10日 | 均值 |

| 代码序 | −11.08% | +8.17% | +14.94% | +4.01% |

**「量比升序」在 3/3 个臂上都是最差或次差（均值 −13.00pp）** → 方向稳定为负。
即：**上一轮的默认排序键（挑「缩量最极端」的票）本身是一条稳定的负 alpha 选票规则。**

### 13.3 结论（修正第十二章）

1. **假设②（排序键逆向选择）成立且方向稳定** —— 上一轮 20 仓 −25.16% 的灾难主要是排序键造成的，
   不是「缩量大跌形态无效」。**我上一轮把容量与逆向选择并列为原因，现在修正为：逆向选择（排序键）为主因。**
   → 教训：**排序键是隐式假设**，与「成本模型里的名义规模」同类，必须显式声明并做消融。
2. **假设③（仓位不回收）不是主因**：缩短 cap 未系统性改善（B 臂 cap250 −25.16% → cap20 −42.60% 更差）。
   但填充率确实极低（B 0.186%~0.664% / C 0.193%~0.539%）→ **B/C 臂在 20 仓口径下根本没被真正测试**。
3. **B/C 臂的数字不可采信**（键间 sd 15.68%~19.74%）：随机键能给出 +20.91%，
   所以 +20.91% 在噪声范围内。
4. **唯一对排序键稳健的是 D 臂（共振标记后 10 日内缩量大跌）**：键间 sd **2.03%~3.35%**。
   cap250 下年化 6.96%~14.94%（均值 ≈10.6%，沪深300 为 9.06%）、夏普 0.438~0.739、
   回撤 −22.07%~−27.50%（**回撤显著大于沪深300 的 −13.42%**）。
5. **全 45 格只有 7 格年化超沪深300、6 格夏普超沪深300** → 无系统性优势。

### 14.4 判负 + 两条新教训（方法论）

**判定：D 臂判负归档。1.9 年窗的 +6.96% ~ +14.94% 是窗口偏差，不是信号。**

- **教训 A（稳健性 ≠ 有效性）**：一个**稳定的负 alpha 同样是稳健的** —— 键间 sd 小只说明"结果可复现"，
  不能推出"结果为正"。上一轮我把「对排序键稳健」当成"唯一值得继续"的证据，**这个推理不成立**。
- **教训 B（噪声地板的估计口径错了）**：我用「键间离散度」当噪声地板，得到 3pp；
  但**窗口间方差才是主导**：同一 D10 臂在 1.9 年窗为 +6.96~+14.94%、在 10.7 年窗为 −2.83~−11.26%，
  **窗口间差异约 20pp，是键间差异的 6~7 倍**。单窗口观测无法支撑"稳健"结论 ——
  **噪声地板必须用「窗口/时段重采样」估计，不能只用「排序键重采样」。**
- 教训 B 与陷阱 ★195（事件级样本量≠独立样本量）同族：都是**低估了真实不确定性**。

### 14.5 这条线的最终状态

### 1.2 关键工程：不复权价重建（**必须实现，否则息率类因子全错**）

前复权价满足 `raw(d) = qfq(d) / f_adj(d)`，其中 `f_adj(d) = Π_{e>d} ratio_e`，
每期除权的 `ratio_e = P_after / P_before = (1 − dy_reported_e) / (1 + sz_ratio_e)`
（`dy_reported` = 东财报告股息率、`sz_ratio` = 每股送转比例；忽略配股，A 股罕见）。

**验证结果**：与东财 val_em 的不复权 close 在 2021+ 重叠 1381 日对拍，**中位相对误差 0.0002%、P90 0.1432%**。

### 1.3 因子构造（精确公式）

| 因子 | 公式 | 说明 |
|---|---|---|
| **`roe_pb`（核心）** | `ROE_TTM(公告日生效, 前向填充) / PB_MRQ / 100` | 巴菲特 1977「股票=股权债券」的直接算子：以净资产买入所能得到的企业回报率 |
| `dy` | 近 365 天已除权 `Σdps / raw_close` | TTM 股息率（**必须用重建价**） |
| `ep` / `bp` | `1/PE_TTM` / `1/PB_MRQ` | 经典价值腿 |
| `gpm_rel` | 销售毛利率 − **同行业中位数**（按 `所处行业` 字段逐日截面） | 护城河代理 |
| `div_years` | 近 5 个自然年中有现金分红的年数（0-5） | 分红持续性 |
| `payout` | TTM `dps / EPS` | 分红率 |
| `roe_streak` | 连续季数（ROE ≥ 12%） | 盈利持续性 |

**排序语义**：`score = 因子降序 rank 分位`（**数值小者优先**），截面逐日计算。

## 四、已验证的负面结论（**接手方请勿重踩**）

1. **质量水平值在 A 股为负 alpha（4 条独立证据）**：`F_roe` −0.216 / `moat_composite_0913` 总收益 −45.3% / Barra `profitability` −6.10% 年化 / factorlab `roe`·`margin` 死家族。→ 不要再用"高 ROE / 高毛利率"做正向选股。
2. **固定阈值止盈止损**：本项目 11 次复核全负（10/10 止盈变体 −24~−84pp、KHunter 止损穷举全退化、打板 14 变体"唯一有效止损=不触发"）。
3. **所有"质量/分红与门"**：本线实测全部降表现（见 §三）。
4. **市场择时闸门**：本线有害；轨A 的教训是"防御族不挂进攻闸门"。
5. **深跌反转 / 超跌类事件 edge 不可组合化**（ADR-0004，6 次同构）。
6. **定价权因子族 5 形式 + 3 对照锚 = 0/8 过 IC 门**；行业龙头（月亮）IC −0.027；行业 CR3 +0.0103。
7. **价格动量/新高**：新高 = 负 alpha（已多次复核）。
8. **组合级回撤状态机（DD 阶梯降暴露）**：价值线 opt7 V1 实测**有害**（年化 13.97%→4.99%、夏普 0.541→0.321、回撤仅 −30.8%→−24.1%；40% 暴露时间占 45.5%）——与轨A「回撤阶梯减仓」（C3a 0.810→0.634）同向、**两载体独立确认：降暴露≠alpha**。
9. **相关簇去重（120d 相关>0.7）**：价值线 opt7 V2 实测**中性偏负**（约束阻塞仅 106 次 vs 行业上限 2,984 次；Δ夏普 +0.017 噪声级、回撤反而恶化 2.1pp）——K=1 行业上限已承担全部分散化。

## 五、关键工程陷阱（我踩过并已修，接手方直接复用结论）

| # | 陷阱 | 后果 | 修法 |
|---|---|---|---|
| 1 | 前复权价 ÷ 原始现金分红额 | 股息率量纲错误、系统性失真 | 先做不复权价重建（§1.2） |
| 2 | 分红表 code（6 位）与价格矩阵列名（`sh/sz` 前缀）不一致 → `if code not in columns: continue` **静默跳过全部股票** | 因子恒为 0，回测结果其实是随机选股 | 建 `code → 列名` 显式映射；加"因子有效值"断言 |
| 3 | **整数因子 rank 并值 → `argsort` 退化为按列序（代码序）取前 N** | 悄悄把"沪市主板"变成选择规则（实测把 0.322 虚高到 0.556） | 二级排序 `combo_score`；定窗时要求截面**离散度**（nunique ≥ 5） |
| 4 | 安慰剂与实盘**相位集不一致**（3 vs 9 相位） | p 值失真（0.067 伪 vs 0.000 真） | 强制同相位集 |
| 5 | **按臂定窗**：不同因子数据覆盖不同，混在同一起点跑 → 早期空仓稀释指标 | 臂间不可比 | 起点 = 首个"有效值≥3N 且离散度足够"的日期 |
| 6 | 复权因子只算现金不算送转 | 送转股的价格断层污染比率 | `ratio = (1 − dy)/(1 + sz_ratio)` |
| 7 | `dividend_year_count` 年份计数写进数组前 N 位 | 分红年数恒为 0 | 改为"年 → 日"映射 |
| 8 | baostock `query_history_k_data_plus` **查询挂起不返回**（login 成功但查询永不返回） | 全 A 估值拉取不可行 | 改用东财 val_em（见陷阱 9） |
| 9 | **"接口只有 2021+" 的误判**：本地文件覆盖 2021+ ≠ 接口只有 2021+ | 白白损失 3 年样本 | **显式日期过滤实测**接口边界（实测可回溯到 2018-01-02） |

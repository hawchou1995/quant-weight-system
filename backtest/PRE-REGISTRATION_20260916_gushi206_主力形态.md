## 一、形态定义（冻结 · 四阶段链条）

素材语义 → 可计算定义（案例刻度锚定：闽东电力 000993，7/1-8/31 横盘 9.6-10.6 → 9/1-9/4 试盘 → 9/7-9/8 洗盘 → 9/9 起 6 连板）：

### S1 建仓区（横盘平台，T−1 回看 60 日）
- `W60 = (HHV(H,60) − LLV(L,60)) / LLV(L,60) ≤ 25%`（案例实测 ≈10%；敏感档 {20%, 25%, 35%}）
- `静默度 = mean((H−L)/C_prev, 60日) ≤ 4%`（案例 1~3%；**仅主臂含此条，敏感臂剥离**）

### S2 试盘（试盘日 t0 ∈ [T−6, T−2]）
- `vr(t0) = amount(t0) / mean(amount[t0−20, t0−1]) ≥ 2.0`（敏感档 {1.5, 2.0, 3.0}）
- `chg(t0) = close(t0)/close(t0−1) − 1 ∈ [0%, +9.5%]`（温和上涨，**非涨停**）
- `上影 = (H(t0) − max(O(t0), C(t0))) / (H(t0) − L(t0)) ≥ 0.15`（冲高回落=试盘特征）

### S3 洗盘（T−t0 ∈ [2,6]，即试盘后 1~5 个交易日）
- `缩量：max(amount[t0+1 .. T−1]) ≤ amount(t0) × 0.9`
- `不破位：min(L[t0+1 .. T−1]) ≥ O(t0) × 0.95`
- （**变体臂 G3 剥离 S3**：无洗盘要求，试盘后直接突破）

### S4 突破/买点（T 日）
- `close(T) > HHV(H, T−1, 60)`（放量突破 60 日新高 = 越过平台与试盘高点）
- `vr(T) ≥ 1.5` 且 `close(T) > open(T)`（放量收阳）
- **T 收盘确认 → T+1 开盘买入**

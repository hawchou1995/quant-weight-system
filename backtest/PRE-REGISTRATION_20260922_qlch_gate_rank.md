## 一、自查交代（本轮立项的直接原因）

`report` 与预注册中我写「熊市门 = HS300 < MA20，**与生产 `short_pool.market_gate` 同口径**」——
该字段确为 `idx_ma20`，**但它在生产里的定位是「短线池市况门控 · 仅提醒，不参与交易」**。

项目内各策略的实际门互不相同：

| 策略 | 实际门 | 翻转频率 |
|---|---|---|
| 超卖伏击 | HS300 < **MA250** | 低 |
| 多因子主仓 | 中证1000 < **MA20**（组合半仓闸） | 高 |
| 基金主仓 | HS300 < **MA200** | 中 |
| 超跌低开低吸 | HS300 < **MA20** | 高 ← **我定的，未验证** |

实测两门不等价：MA20 门触发 1,269/2,604（48.7%），MA250 门 1,138/2,604（43.7%），**Jaccard 仅 0.462**。
**→ 门周期是我的选择，从未与 MA200/MA250 对比测试。记入缺陷台账。**

## 三、实验 A · 熊市门口径（5 臂）

| 臂 | 门 | 说明 |
|---|---|---|
| **A0** | HS300 < MA20 | 现状（对照） |
| A1 | HS300 < MA60 | 中短 |
| A2 | HS300 < MA200 | 基金主仓同款 |
| A3 | HS300 < MA250 | 超卖伏击同款 |

**必须同时报告暴露率**（持仓日占比）——不同 MA 周期的翻转频率不同，**不是干净的单一变量**，
故读法为「同暴露下比单笔质量 + 比风险调整指标」，不单看年化。

## 四、实验 B · TopK 排序规则（4 臂，K 固定 = 3）

**背景**：`PRE-REGISTRATION_20260921_qlch_poscap.md` §三 明写「随机抽取，不做任何排序」——
理由是"排序会引入新的选择规则，与单一变量原则冲突"。**该理由在那一轮成立，但代价是策略无买入优先级、不可执行。**

| 臂 | 排序键 | 取法 |
|---|---|---|
| **B0** | 随机 | 现状（对照，5 种子均值） |
| B1 | **超跌深度**（ret20 越负越前） | 取前 3 |
| B2 | **gap 深度**（越负越前，T+1 开盘已知 → 可执行） | 取前 3 |
| B3 | 综合分（超跌深度 z + gap 深度 z 等权） | 取前 3 |

**可执行性检查**：三个排序键在「T+1 开盘下单时刻」全部已知（ret20 为 T-1 收盘，gap 为 T+1 开盘价算得）。
无前视。

## 五、判据

**实验 A**：
- 门必须**可复现且暴露率可接受**（持仓日占比 ≥ 8%，否则样本不足）
- 首选判据：**夏普**（风险调整），次选年化
- 硬门：50bp 档按天等权持仓日净均 > 0

**实验 B**：
- **B1/B2/B3 任一 vs B0（随机）**：夏普提升 ≥ +0.05 **且** 不劣化回撤
- 若三个排序都**不如随机** → 判「该策略无有效排序维度」，保持随机，并在看板明确标注「本策略为等权随机取 K，无可执行优先级」
- 若排序有效 → 登记为候选，随封存集验收

**分年一致性**：任一年按天等权不为负的年份数 ≥ 2/3

## 六、预设退出

1. 实验 A：全部门周期夏普差异 < 0.05 → 判「门周期不敏感」，**保持 MA20 但改写文档口径**（不再声称"生产同口径"）
2. 实验 B：三个排序全不如随机 → **保持随机**，接受"不可执行优先级"并在看板标注（不再宣称可买 TopK）
3. 两项都不过 → 不改生产口径，只更新文档与看板标注

**禁止**：不得为让某臂过门而调 gap/分位带参数；不得用已用 OOS 段选型。

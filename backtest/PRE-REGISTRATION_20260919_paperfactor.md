# 预注册 · 2026-09-19 · 论文因子 BTQ「暴露×流量」立项（R-paperfactor-0919）

> 冻结时间：2026-09-19（先冻结后跑；本轮已过 factor_morgue 前置闸）
> 来源：arXiv:2609.05162《Quantity, Risk, and Return》可迁移部分 = 因子定价的**交互项**
> 　　E[r] = Σμ_k β_ik + Σλ_k β_ik·q_k（暴露 × 该因子被噪声交易流冲击的量）
> 论文原形式用共同基金持仓造 q —— **A 股仅季报前十大重仓、覆盖偏差大，不可复现**；
> 故本轮只取「**暴露 × 流量**」这一**结构**，流量用成交额造代理。

## 一、因子定义（冻结）

```
mkt_t      = 全市场等权日收益（mask 内均值收盘收益率）
beta_i,t   = Cov60(r_i, mkt) / Var60(mkt)        尾随 60 日
flow_mkt_t = 全市场总成交额 / MA60(总成交额) − 1   （市场资金流冲击）
F_i,t      = beta_i,t × flow_mkt_t
```

- 全部尾随窗口（≤t），无前视；截面不做额外标准化（保留 beta 的量纲）
- 面板：factorlab_0913/panel_0913.pkl（1386×3209，2021-01-04~2026-09-18），warmup 60 日

### 首跑被抓出的三个缺陷（全部已修，记录在案）
1. **因子含溢出值**：`flow_mkt` 除零 + `beta` 未截断 → 分位画像出现 20945040% 荒谬值。
   修复：flow_mkt 截 [−1,3]、beta 截 ±5，并加 `inf==0` 断言自检。
2. **变量名撞车**：本脚本的 `F` 被 exec 进来的轨B 前缀里的 `F = 20`（调仓频率）覆盖 → 
   `TypeError: int object is not subscriptable`。修复：改名 `FAC`。
3. **P1 分位分组没真正取子集**：算了 `sel` 却未用于均值 → 五组结果全同。已修（searchsorted 分桶）。
4. **前向收益被极端值污染**：面板含退市股价格塌陷，原始均值被污染（P0/B3 = 2094 万）。
   修复：R10 缩尾（剔 |ret|>200% 与 <−50%，共 40 格）。**P2/P3 不受影响**（走引擎 ELIG3 域）。

**注**：三条修复均属「技术正确性」缺陷，**不改变结论**——FAC 的 RankIC 本身就只有 −0.0077。

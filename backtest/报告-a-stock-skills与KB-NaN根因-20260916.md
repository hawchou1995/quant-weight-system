# a-stock-skills 研究结论 + KB Top5 NaN 根因（2026-09-16）

## 一、`lucasxing1/a-stock-skills`：**没有因子可挖**（第 1 步完成）

**仓库实况**：仅 3 个真文件（README.md / SKILL.md / scripts/a_stock_analysis.py），129 KB。
**性质**：**东财妙想（mx）API 的 OpenClaw skill 包装**——能力全在服务端：

| 工具 | 作用 |
|---|---|
| `mx-select-stock` | 自然语言条件选股（"PE<20 的银行股"） |
| `mx_selfselect` / `mx_data` / `mx_search` | 自选股 / 行情基本面 / 新闻研报公告检索 |
| `stock-monitor-skill` | 成本百分比、均线金叉、RSI 监控预警 |

**它的「A股特色指标」= 数据类别清单，不是公式**：
```
涨停板(连板数/封板率/炸板率) · 龙虎榜(机构买入/游资动向) · 融资融券(融资余额/融券余量)
股东人数(筹码集中度变化) · 限售股解禁 · 股权质押 · 商誉减值 · ST/*ST
```
→ **逐条对照**：这 8 类**我们本地或新管道已全部覆盖**（涨停/连板→A5 与打板族；龙虎榜→lhb_detail 12.5 万行 + 席位买卖各 37 万行；融资融券→margin（续跑中）；股东人数→holdernum 15 万行；解禁→unlock；质押/商誉→**缺**；ST→st_events 4,780 行）。

**结论**：该仓库对「因子挖掘」**零增量**（无公式可回测）；其真实价值 = **妙想 API 的调用面**，而妙想 key 我们已拿到（`MX_APIKEY` 已 setx，`connector_mx.py` 已通）。**唯一新增待办**：股权质押 / 商誉减值 两类数据本地确实缺（可作为下一批抓数候选）。

## 二、KB Top5 的 NaN 根因：**事件密度不足，不是 bug**（附实证）

`build_fenzhi`（分歧弱转强，原文逐句复刻）在**主板全域**跑出的计数器：

```
zt(涨停)=74,601  nb(二板)=30,432  g1=12,383  g2=438,343  g3=95,561  g4=196,302
xg(分歧弱转强 最终信号) = 164        stocks_with_xg = 160
```

**判定**：信号**确实会触发**（164 次 / 160 只），但密度 = 164 ÷ (1231 天 × 3209 只) ≈ **0.004%，约 0.13 次/日**。
→ **用 Top20 月频组合承载它是形态错配**：一个月最多 ~2.7 个新事件、叠加 10/20 日新鲜度窗口后同时持仓常为 0~3 只 → **组合腿为空 → 指标 NaN**。

**处置建议（二选一）**：
1. **改为稀疏事件逐笔评估**（每笔独立：T+1 开盘买入、固定持有窗口 10/20 日，统计胜率/均值/分布 + 安慰剂）——不再套 Top20 组合框架；
2. 直接按项目历史口径判定「**不可组合化**」（与"深跌反弹不可组合化"同族），仅留事件统计备查。

**同名教训**：本项与同舟「事件回测三件套」的对比值得记——**同舟那套是"已实现收益"（疑似前视）**，我们这套是**自己复刻的事件链（PIT 干净）**；今后事件类研究一律走后者，前者的收益字段禁用。

## 一、结论先行

**三轨都不采纳。** 预注册的双条件闸（相位中位夏普 ≥ 对照 + slip50 不劣化）在 Bonferroni 要求下无一达标：

- **轨C（FB3 基金主仓，生产引擎口径）**：约束对收益/夏普的影响全在噪声内（配对中位差 ≤ +0.012），N=1 的 slip50 还劣化 → **明确否决**。
- **轨A（冷门低波）/ 轨B（SUPER）**：有**轻微正向迹象但相位不稳**（详见 §三），复刻口径下 N=2 / N=1 双条件过、配对检验不过 → **不达标，不改生产**；建议挂影子轨观察（与 pct40 同机制）。
- 用户直觉「行业对冲会好点」**在数据上不成立**：约束不是收益来源，最多是浅层的风险平滑，且不稳定。

## 四、风险与实现备注

- **约束会改变持仓分布**：轨A「冷门低波」天生在公用事业/环保/银行等低波板块扎堆，N=1/2 会强制扩散到更高波动标的 → 这是它 slip50 改善但收益下降的原因。
- **基金轨的行业键是名称法**（119 关键词 / 38 标签，未分类 5.3%）：主动混合基金多归入「均衡配置」（33.2%），这类宽标签按 Q2 拍板**豁免约束**——若改成重仓股穿透口径，结论可能不同（本轮未做）。
- **实现**：`short_engine` 新增 `max_per_industry` / `industry_of` / `offset`（默认关闭，生产不受影响）；实验脚本 `backtest/industry_cap_fund_0914.py`、`backtest/industry_cap_ab_0914.py`。

## 五、局限（如实申报）

1. **轨A/轨B 用复刻口径**：其生产回测脚本原已不可考（轨A）或依赖冻结面板（轨B）。复刻基线（轨A 相位中位夏普 0.400；轨B 0.804）**低于历史声称**（轨A 1.238 已被项目自身审计判定不可复现；轨B 声称 phmed 1.151）。
2. 相对比较（同口径 N vs N0）**内部有效**，但**绝对水平不可用于对外引用**。
3. 若未来要在此基础上改生产，建议：先挂影子轨（与 pct40 同机制）跑满 3 个月，再按硬闸终判。

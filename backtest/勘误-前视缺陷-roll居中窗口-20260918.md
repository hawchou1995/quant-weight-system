## 一、缺陷（根因）

`scipy.ndimage.maximum_filter1d / minimum_filter1d` 默认 `origin=0` 是**居中窗口**：
size=n 覆盖 `[i - n//2, i + n - 1 - n//2]`，**含未来 n//2 天**。

最小实验（`_t.py` / `_t2.py`）:
```
input    [ 0.  0. 10.  0.  0.  0.  0.]
size=3   [ 0. 10. 10. 10.  0.  0.  0.]    <- idx1=10，用的是 idx2（未来）
size=5   [10. 10. 10. 10. 10.  0.  0.]    <- idx0=10，前视 2 天
```

R-tdx6 起所有臂共用的 `roll(a, n, kind)` 调用该函数且未设 origin →
**每个用 roll 构造的指标都前视 n//2 天**：n=3→1、5→2、6→3、9→4、10→5、13→6、20→10、**60→30 天**。

正确写法（尾随窗口 `[i-n+1, i]`）：`origin = n - 1 - n // 2`。
实测验证：峰值只向前传播、无反向渗漏（`_t3.py`）。

## 五、教训（已入陷阱库 ★175）

1. **库函数默认参数必须实测验证**，尤其「滤波/卷积/窗口」类——`origin`/`mode`/`center` 语义各库不同，
   读文档不如跑一个 7 元素最小实验（本次 `[0,0,10,0,0,0,0]` 一击定案）。
2. **「好到不可能是真的」是最高优先级告警**：20bp CAGR 257% / Sharpe 6.56 / 回撤 −11% 出现时，
   第一动作是查前视，不是写报告。
3. **交叉对拍是唯一可靠把关**：本轮靠「**无信号全市场对拍**」定位——任何因子必须先证明
   「它作用于**全部**标的时效应有多大」才能声称是信号贡献；**若某"信号"的效应量级与全市场同分位组相当，
   那它就不是信号**。此对拍应固化为因子入库前的强制步骤。
4. 前视只会**抬高**表现。凡修正后转正/转负的结论，其**符号本身不可信**，必须重跑后才可表态。

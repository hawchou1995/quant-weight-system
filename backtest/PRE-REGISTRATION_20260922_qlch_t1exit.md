# PRE-REGISTRATION · T+1 合规出口重测（★198 复发修正）（R-qlch-t1exit-0922）

> 触发：用户 2026-09-22「A股现在可以当天实现买卖？」——**问对了，抓出致命缺陷**。
> **A 股 T+1 交割：当日买入当日不得卖出**，须待次一交易日。

## 一、缺陷陈述（★198 同类复发，自伤第二次）

`qlch_paper_20260921.py` 与全部回测脚本的出口为：

```
entry_px = O[t, j]      # T+1 开盘买
exit_px  = C[t, j]      # T+1 收盘卖
entry_date = exit_date = D   # 同一交易日
```

**同日开盘买 → 同日收盘卖 = T+0 回转，在 A 股无法执行。**

**这不是新陷阱**——项目陷阱库已记录 ★198（`gushi52` 轮 2026-09-19）：
> 「执行层两 bug（★198 T+0 回转假 +171%、★199 停牌假触发+NaN 毒现金被中位数掩盖）均被"好到不可能是真的"抓出」
> 修法：`exit = entry_day + K`（K=1 = 次日离场）

**我在陷阱库有这条记录，本轮仍复发。** 记入缺陷台账（本会话第 5 次自伤）。

**后果**：`超跌低开低吸` 全部已发布数字作废——含 `+18.78% 年化 / 夏普 1.254 / 回撤 −15.12%`、
Top3 排序、门对比、持仓上限、主板限定等**全部基于非法出口的读数**。

## 二、口径（冻结 + 唯一改动）

**冻结**（沿用现生产配置）：
- 入场：T 收盘判定候选（超跌 `ret20(T-1)≤−7.31%` + B4 分位滤网 + 量比≥1.2 + 非ST + MA20 熊市门）
- T+1 开盘买，gap ∈ [−5%,−2%] 才买，成交价 = T+1 开盘
- **单票权重 = min(1/n, 1/K)，K=3**
- 成本：往返 20bp 主档 + 50bp 压力档
- **唯一改动 = 出场规则**

## 三、臂设计（n_trials = 4，E0 为对照不计）

| 臂 | 出场 | T+1 合规 | 说明 |
|---|---|---|---|
| **E0** | T+1 收盘卖（同日） | ❌ **非法** | 原口径，**仅作对照**，用来看"假数字有多大" |
| **E1** | **T+2 开盘卖** | ✅ | 持有一夜，最接近原口径的合法版本 |
| **E2** | **T+2 收盘卖** | ✅ | 持有 2 天 |
| **E3** | **止盈 +8% / 止损 −10%**，上限 20 日 | ✅ | 用户指定（"按止盈止损策略跟"） |
| **E4** | **止盈 +15% / 止损 −20%**，上限 20 日 | ✅ | 宽档，对应项目「双条件止损」 |

### E3/E4 触发判定（按陷阱库 179–186「单笔成交层面的微观语义」）

| 规则 | 实现 |
|---|---|
| 止损止盈用 low/high 非 close | 日内触及即触发，不等收盘 |
| **同 bar 止损优先** | 同一日内两线都触发时，按止损价成交 |
| **跳空按 open** | 开盘价直接穿过目标价时，按开盘价成交（不是目标价） |
| 末仓显式处理 | 上限 20 日到期当日**按收盘价**强制平仓 |
| 持有期 | 入场日 = T+1，出场日 ≥ T+2（T+1 不可卖） |

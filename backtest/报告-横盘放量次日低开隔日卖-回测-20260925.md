## 1. 规则量化口径

| 你的话 | 量化定义（信号日 T） |
|---|---|
| 横盘 | 前 20 日振幅 `RANGE = (max(high,20)−min(low,20))/close[T−1]` 横截面升序分位 ≤ Pq **且** `|close[T]/close[T−20]−1|` 分位 ≤ Pq |
| 缩量（横盘期量能） | `VOLMA20_prev / VOLMA60_prev ≤ 1.0` |
| 突然放量 | `VOL[T] / VOLMA20_prev[T] ≥ K`（量比） |
| **次日低开买入** | `open[T+1] / close[T] − 1 < 0`（基准=任意低开），并测 `≤ −1% / −2% / −3%` |
| **隔一天尾盘卖出** | **买入日 T+1 → 卖出日 T+2 尾盘（收盘）**；另测 T+2 开盘 / T+3 尾盘 |
| 股票池过滤 | 有效交易日 ≥250、`close ≥ 2元`、20 日均额 ≥ 2000 万 |

**「隔一天」的两读法我都跑了**：主口径取 **T+2 尾盘**（A 股 T+1 制度下「买入日之后最早可用的尾盘」），另一读法 T+3 尾盘并列披露（结论一致，见 §4.1）。

**读法**
1. **「低开」的 t(同日超额)=15.75** —— 390 万笔样本、日聚类检验，这是本报告里唯一**压倒性显著**的因素。对照组「全部高开」是 **−13.66**，方向完全对称。
2. **加「横盘」反而变差**（+0.2103% → +0.1523%）：横盘条件筛掉的正是「温和低开、次日修复」那批最稳的样本。

## 5. 判定与建议

### 5.1 判定：**不作为独立策略上线**（三条独立理由）

1. **忠实实现过不了闸**：你的原规则（横盘+放量+低开）@20bp 年化 −3.25%、四闸 2/4。
2. **可实操性否决（决定性）**：边只存在于每日持有上百只的横截面。按低开深度挑 3~20 只 → 年化 **−15%~−30%**（排序是反向筛选）；随机挑 3 只也是 −5.47%。个人账户无法持有 233 只/日。
3. **风险收益比差**：即使最好的剥简口径，最大回撤 **−47%~−49%**、Calmar ≈ 0.25（年化 12.4%/回撤 49%）。

### 5.2 但你的规则里有三个可直接复用的真结论

1. **「次日低开」= 强短线反转因子**（t(同日超额)=15.75）。建议作为**买点/择时层**接入你现有的选股池：**已有的选股结果里，把「次日低开 1~3%」作为建仓时点过滤器**，而不是单独跑一个组合。
2. **「尾盘卖」优于「开盘卖」**（+0.186pp/笔）—— 与上一轮微信文章回测里「追高买入后次日即失血」互为镜像。
3. **低开幅度有最优区间 −1%~−3%**，深跌（≤−3%）不要碰。

### 5.3 若仍要试：最小可行方案

- 只做 **R2 口径**（低开 −3%~−1%），**不做深度排序**（随机或按流动性抽样）
- **成本必须 ≤10bp**（万1~万2.5 佣金 + 零滑点，用限价单挂在开盘价）；20bp 以上直接不划算
- 小仓位（单票 ≤1%，同时 ≥50~100 只），纸面前向 OOS ≥120 交易日再评估
